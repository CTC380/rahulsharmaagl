AGL Applications · LED AGL Retrofit

LED AGL RETROFIT PROJECTS

LED technology can be considered for upgrading suitable existing Airfield Ground Lighting (AGL) installations. An LED retrofit should be evaluated as a complete system so that the new lighting equipment operates correctly with the existing airfield electrical infrastructure.

A retrofit project may involve selected runway, taxiway, approach or visual guidance equipment, while retaining suitable parts of the existing AGL installation. The evaluation should consider the existing equipment, electrical configuration, control system, installation conditions and project requirements.

02 · Why Retrofit

Why Consider LED Retrofit?

An LED retrofit project may be considered as part of an airport lighting modernisation programme. However, the existing CCRs, series circuits, transformers and connectors were selected for the original lamps.

LED conversion should therefore be evaluated as a system upgrade rather than simply a change from one light source to another.

03 · System Evaluation

Existing AGL System Evaluation

Before replacing existing lighting equipment with LED units, the surrounding AGL system should be reviewed.

CCR Compatibility

The existing Constant Current Regulator and its operating characteristics should be considered before introducing new LED equipment.

  • Relationship between CCR and series circuit
  • Proposed LED fixture characteristics

Isolating Transformers & Connectors

Existing transformers and primary/secondary connectors should be checked for suitability with the proposed LED equipment.

  • Transformer characteristics
  • Primary connector compatibility
  • Secondary connector compatibility
  • Installation condition

Series Circuit, Cable & Control

The series circuit, cable condition and control system should be reviewed before introducing replacement LED fixtures.

  • Circuit configuration & electrical characteristics
  • Primary & secondary cable condition
  • Lighting controls & monitoring interfaces
04 · Process

LED Retrofit Process

A typical LED AGL retrofit can involve the following stages.

Existing system assessment — understand the AGL configuration, electrical infrastructure, controls and circuit arrangement
Application identification — determine which components are being upgraded
Compatibility review — CCR, series circuit, transformers, cables, connectors and control system
Equipment selection — identify suitable replacement equipment for the application
Installation — replace or upgrade equipment per the approved arrangement
Testing — applicable electrical, functional and lighting-performance checks
Commissioning — confirm the upgraded system operates within project requirements

12 · FAQs

Frequently Asked Questions

Can any existing AGL system be converted to LED?
Not automatically. Compatibility with the existing electrical and control infrastructure should be evaluated before introducing LED equipment.
Do isolating transformers need to be checked during LED retrofit?
Yes. Transformer characteristics and compatibility form part of the system-level evaluation.
Should the CCR be checked before LED retrofit?
Yes. The existing CCR and series-circuit operating conditions should be considered before introducing new LED equipment.
Can LED retrofit include taxiway lighting?
Suitable taxiway lighting applications can be evaluated as part of an LED upgrade project.
Can existing AGL cables be retained during an LED retrofit?
Existing cables may be retained where they are suitable for the proposed system. Their condition and compatibility should be evaluated as part of the retrofit assessment.
Can existing transformers and connectors be retained?
Existing transformers and connectors may be retained where technically suitable. Their characteristics, condition and compatibility with the proposed LED equipment should be checked.
Is an LED retrofit the same as replacing the light fixture?
No. An LED retrofit should consider the fixture together with the CCR, series circuit, transformers, cables, connectors and control arrangement.
Can LED retrofit be part of runway rehabilitation?
Yes. Suitable LED upgrades can be incorporated into broader runway or taxiway rehabilitation projects where they meet the project requirements.
