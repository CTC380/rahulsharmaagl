The Fact CCR & power supply

CCR output measurement is how the CCR knows what it is delivering. An output current sensor measures the loop current and feeds it back to the controller, which compares it with the target for the selected brightness step and adjusts the power stage until they match. That feedback is what keeps the current constant as the load or supply changes.

The same measurements appear on the display as output current, and usually voltage and power, and they drive alarms such as low, high or zero current. Voltage and power follow the load; current should sit at the value for the step. For an independent check use a true-RMS instrument at an approved test point, because the output is not a clean sine wave. Never open a live loop to insert a meter: the CCR will drive the voltage up across the break. See CCR controller, circuit load and series circuit current path.

  1. Read the display. Note the brightness step and the output current, voltage and power.
  2. Compare with the step. The current should match the value for that step.
  3. Check independently if needed. Use a true-RMS instrument at the approved test point, under the site permit.
  4. Compare with records. A drift in voltage or power suggests the load has changed.
  5. Investigate alarms. Low, high or zero current points to the CCR, an open loop or a fault.

FAQ

Frequently Asked Questions

Q1What is CCR output measurement?

The CCR senses its own output, mainly the loop current, and uses it in two ways: as feedback so the controller holds the current at the selected brightness step, and as readings (current, voltage and power) shown on the display and used for alarms.

Q2Why does the CCR measure the output current?

Because current is what the CCR regulates. The controller compares the measured current with the target for the brightness step and adjusts the power stage until they match, so the loop current stays constant as the load or supply changes.

Q3What readings does a CCR normally show?

Typically the output current, and often the output voltage and power as well, together with the selected brightness step and any alarm. Voltage and power follow the load, while current should sit at the value for the step.

Q4How can the output be checked independently?

A competent person can use a true-RMS instrument connected at the approved test point, or a clamp probe rated for the circuit, under the site permit. The output waveform is not a clean sine wave, so a simple average-reading meter can be wrong.

Q5Why must a live loop never be opened to insert a meter?

The CCR keeps driving its set current, so opening a live loop makes the voltage across the break rise sharply and is dangerous. Measure only at approved points, or isolate the circuit under site procedures first.

Q6What does an unusual reading tell you?

Current well off the set value points to a CCR or sensing problem, or to a loop that is open or heavily faulted. A voltage or power reading that has drifted from earlier records suggests the load has changed, for example failed fittings or an earth fault. See open circuit and circuit load.
