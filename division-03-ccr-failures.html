Initial Issue

Key principle — A CCR failure should be recorded by the actual failure mode, operating symptom, evidence, root cause and effect on the series circuit — not simply as "CCR failed." Capture three separate levels for every event: Failure Event (what happened), Failure Mode (how it happened) and Root Cause (why it happened).

Diagnostic principle — Events like "CCR shutdown" or "protection trip" are symptoms, not root causes. Always trace the failure chain back to its initiating condition, and establish whether the CCR itself is the source of the problem or whether it is correctly responding to an abnormal connected series-circuit load.

CCR-01 Output Instability
Failure Definition

CCR output is not stable at the commanded operating condition.

Typical Symptoms
  • Output current fluctuates
  • Current does not settle
  • Fixture intensity varies
  • CCR indication continuously changes
  • Repeated alarms
  • Intermittent circuit behaviour
Possible Failure Areas
  • Current-regulation system
  • Thyristor/power electronics
  • Controller
  • Feedback system
  • Internal wiring
  • Load condition
  • Cooling/thermal condition
Investigation — Record
  • Commanded intensity step
  • Actual output current
  • Output-voltage condition
  • Load condition
  • Alarm status
  • CCR temperature
  • Historical behaviour
  • Event/alarm logs
RCA Focus

Determine whether instability originates from the CCR itself or the connected series-circuit load.

CCR-02 Thyristor Failure
Failure Definition

Failure of the CCR power-control thyristor or associated thyristor circuit.

Possible Symptoms
  • No output
  • Incorrect output current
  • Output instability
  • Protection trip
  • Unable to achieve commanded intensity
  • Abnormal current regulation
Investigation — Check
  • Thyristor condition
  • Gate/control signal
  • Power circuit
  • Heat sink
  • Thermal condition
  • Associated protection
  • Controller command
Evidence
  • Fault/alarm indication
  • Test results
  • Damaged component
  • Thermal condition
  • Replacement component details
CCR-03 Cooling-Fan Failure

Failure of the CCR cooling fan resulting in inadequate heat removal.

Symptoms
  • Increasing internal temperature
  • Fan alarm
  • Over-temperature condition
  • CCR derating
  • CCR shutdown
  • Repeated thermal trips
Possible Causes
  • Fan motor failure
  • Bearing failure
  • Dust contamination
  • Blocked airflow
  • Electrical supply failure
  • Fan-control failure
Investigation — Check

  • Fan supply
  • Fan rotation
  • Airflow
  • Filters
  • Temperature
  • Fan alarm
  • Maintenance condition
CCR-04 Controller Failure

Failure of the CCR control electronics responsible for regulating or controlling CCR operation.

Symptoms

  • Communication interfaces

CCR-05 Protection Trip
Failure Definition

CCR protective function operates and removes or limits output.

Possible Causes
  • Overcurrent
  • Earth fault
  • Over-temperature
  • Internal component fault
  • Abnormal load
  • Electrical transient
  • Protection-system condition
Investigation Principle

Do not treat the protection trip itself as the final root cause. Determine: why did the protection operate?

CCR indication or output progressively deviates from its calibrated/reference condition.

Symptoms

CCR-08 Output-Current Deviation
Failure Definition

Actual CCR output current differs from the required/commanded value.

Failure Modes
  • Low output
  • High output
  • Unstable output
  • Incorrect step output
Investigation

Record current at each applicable intensity level: commanded step, expected current (reference), actual current (measured), deviation (calculated), load/circuit condition, CCR status (normal/fault) and corrective action.

CCR-09 Current Regulation Failure
Failure Definition

CCR is unable to maintain the required constant-current output.

Symptoms
  • Current continuously changes
  • Incorrect output
  • Fixture intensity variation
  • Protection activation
  • Failure at particular intensity steps
Possible Areas
  • Power-control section
  • Thyristors
  • Controller
  • Feedback
  • Load
  • Internal wiring
  • Thermal condition
Key Distinction

Output-current deviation = measured output differs from expected. Current regulation failure = CCR cannot maintain the required regulated output.

CCR-10 Intensity-Step Failure
Failure Definition

CCR fails to correctly produce one or more commanded intensity levels.

Symptoms
  • Step not available
  • Incorrect current at a particular step
  • Two steps producing similar output
  • Incorrect transition
  • Step-related alarm
Investigation

Test each available intensity level systematically and record commanded step, expected current, actual current, deviation, transition response and alarm status. This should be linked to CCR testing and commissioning records.

CCR-18 Cooling-System Failure
Failure Definition

Failure of the CCR's overall cooling arrangement. This is broader than Cooling-Fan Failure.

Possible Causes
  • Fan failure
  • Blocked airflow
  • Filter contamination
  • Heat exchanger problem
  • Ventilation failure
  • Internal temperature rise
  • Cooling-control failure
Symptoms
  • High internal temperature
  • Reduced performance
  • Thermal alarm
  • Over-temperature
  • Shutdown
Relationship

Cooling-fan failure = specific failure mode. Cooling-system failure = wider system-level condition.

CCR Operational & Load Failures

CCR-20 CCR Shutdown
Failure Definition

Unintended or fault-induced cessation of CCR operation.

Possible Causes
  • Protection trip
  • Over-temperature
  • Auxiliary-supply failure
  • Controller failure
  • Internal power failure
  • Load-related problem
  • Severe electrical fault
Important Investigation Rule

"CCR shutdown" is the event/symptom. The investigation must identify the actual initiating failure. For example:

CCR SHUTDOWNOVER-TEMPERATURECOOLING-FAN FAILURE

or:

CCR SHUTDOWNPROTECTION TRIPSERIES-CIRCUIT EARTH FAULT
CCR-21 Intermittent CCR Operation
Failure Definition

CCR repeatedly starts, stops or behaves abnormally without remaining continuously failed.

Symptoms
  • Random shutdown
  • Repeated restart
  • Intermittent output
  • Temporary alarms
  • Unstable current
  • Fault disappears after reset
Possible Causes
  • Loose internal connection
  • Thermal problem
  • Controller fault
  • Communication problem
  • Auxiliary supply instability
  • Protection issue
  • Load-related condition
Investigation

This failure requires particularly strong evidence: event logs, alarm history, operating time, temperature, output current, load condition, and the number/timing of occurrences.

CCR-22 Load-Related Failure
Failure Definition

CCR abnormal behaviour caused by the connected AGL series-circuit load rather than an isolated CCR component failure.

Possible Causes
  • Incorrect circuit load
  • Cable fault
  • Earth fault
  • Short circuit
  • Open circuit
  • Transformer problem
  • Fixture failure
  • Excessive load
  • Abnormal circuit condition
Symptoms
  • Output instability
  • Protection trip
  • Current regulation problem
  • CCR shutdown
  • Abnormal output current
Critical Diagnostic Principle

Before replacing a CCR component, establish whether the CCR is actually the source of the problem. A CCR can correctly respond to an abnormal series-circuit condition.

Division 03 vs. Division 02

Division 02 captures failures in the electrical path feeding the circuit — cable, connector, termination, insulation, protection. Division 03 captures failures within the CCR itself — power electronics, cooling, controls, calibration, indication and auxiliary supply. Where a CCR trips or shuts down, always confirm whether the initiating failure is internal to the CCR (Division 03) or an abnormal series-circuit condition upstream (Division 02) before replacing any CCR component.

Frequently Asked Questions

Quick answers about Constant Current Regulator (CCR) failures, as covered in Division 03 of the AGL Failure Database.

Q1What is Division 03 — CCR Failures in the AGL Failure Database?

Division 03 covers failures within the Constant Current Regulator itself. It contains 22 published topics (CCR-01 to CCR-22) spanning output regulation, power electronics, cooling, controls, protection, communication, indications, auxiliary supply and load-related problems.

Q2Which CCR failures does Division 03 cover?

Output instability, thyristor failure, cooling-fan failure, controller failure, protection trip, communication failure, calibration drift, output-current deviation, current regulation failure, intensity-step failure, alarm failure, display failure, remote-control failure, local-control failure, internal wiring failure, terminal overheating, auxiliary-supply failure, cooling-system failure, over-temperature condition, CCR shutdown, intermittent CCR operation and load-related failure.

Q3How are the 22 CCR topics grouped?

They are grouped into five sets: CCR Output & Power-Control Failures (6 topics), CCR Regulation & Performance Failures (4), CCR Indication & Control Failures (4), Internal Electrical & Thermal Failures (5) and CCR Operational & Load Failures (3).

Q4What three levels should be captured for every CCR event?

Every CCR event should record a failure event (what happened, for example a CCR shutdown), a failure mode (how it happened, for example an over-temperature condition) and a root cause (why it happened, for example cooling-fan failure, blocked airflow or a maintenance deficiency). This keeps the database from becoming a simple list of symptoms.

Q5Is a CCR shutdown a root cause?

No. A CCR shutdown is often a consequence. In one recorded chain, a cable insulation problem causes an earth fault, which causes a CCR protection trip, a CCR shutdown and a lighting outage. Here the initiating failure is the electrical fault in the series circuit, not the CCR.

Q6How do Division 02 and Division 03 differ?

Division 02 covers failures in the electrical path feeding the circuit, such as cable, connector, termination, insulation and protection. Division 03 covers failures within the CCR itself: power electronics, cooling, controls, calibration, indication and auxiliary supply. When a CCR trips or shuts down, confirm whether the initiating failure is internal to the CCR or an abnormal series-circuit condition upstream before replacing any CCR component.

Q7Where should the investigation start for a given CCR symptom?

The diagnostic matrix maps each symptom to a first investigation focus. For example, output instability points to regulation and load, thyristor failure to the power section, cooling-fan failure to fan and airflow, controller failure to the controller and auxiliary supply, communication failure to the interface and network, and a protection trip to determining the initiating fault.

Q8What should be recorded for a CCR failure?

Each record should include identification (failure ID, airport/project, CCR identification, manufacturer, model, rating, circuit served, installation date), failure information (date/time, category, mode, symptoms, intensity step, output current, CCR temperature, load condition, alarm and event-log information), investigation results, evidence and photographs, RCA (immediate cause, root cause, contributing factor, failure mechanism) and restoration details.

Q9How are failure severity and operational impact classified?

Every failure receives a severity classification, plus operational-impact tagging. The classes are Critical / Safety-Critical (immediate operational or safety risk), Major / Operationally Critical (significant availability impact), Moderate (reduced performance, not yet critical), Minor / Non-Critical (limited or no operational effect), and Degradation / Intermittent / Latent (a developing or hidden fault).

Beyond the Alarm

DON’T JUST RESET THE CCR. UNDERSTAND WHY IT TRIPPED.

A CCR fault can come from a thyristor failure, a current-transformer error, a control-logic fault or a downstream circuit problem — real troubleshooting means understanding CCR architecture well enough to trace the alarm back to its actual source.
