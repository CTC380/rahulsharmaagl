Division 06 of 25 · TEST Series

Testing Forms

The 25 forms that make up the formal AGL testing and test-evidence layer — every insulation resistance value, CCR step, isolation transformer check, cable, earth, photometric measurement, and factory/site acceptance test recorded, assessed against an acceptance criterion, and carried through to a certified test report. Grouped into Electrical Testing, Equipment Testing, Photometry, and Factory/Site Testing, this division proves the measured technical performance of the AGL system, complementing the condition-based evidence captured in Division 05 Inspection.

A · Electrical Testing

10 of 10 forms
TEST-01 Insulation Resistance Test Report Test Report
Purpose

To document insulation-resistance testing of AGL electrical circuits, cables and equipment.

Key Fields
  • Test Report No. / Project / Airport / Location / Circuit ID / Equipment or cable ID
  • Date / Tester / Test engineer-technician / Witness
  • Drawing reference / Applicable specification
  • Instrument make, model, serial number, calibration certificate and calibration validity
  • Test voltage/range and measured resistance (MΩ) at each test point
  • Required acceptance criterion vs. actual value / Pass-Fail / Remarks
  • Final certification: tested by, checked by, witnessed by, approved by
Feeds TEST-11 CCR Test Report and TEST-12 Isolation Transformer Test Report, where insulation values form part of equipment acceptance.
TEST-02 Continuity Test Report Test Report
Purpose

To verify electrical continuity of conductors, circuits and connections.

Key Fields
  • Circuit ID / Cable ID / Equipment ID / Test points
  • Test instrument / Instrument ID / Calibration reference / Test method
  • Measured resistance-continuity / Acceptance criterion / Result
  • Verification: correct circuit, correct test points, continuity established, no open circuit, identification verified
TEST-03 Cable Test Report Test Report
Purpose

To provide a consolidated test record for installed AGL cables.

Key Fields
  • Cable ID / Circuit ID / Cable type, size, manufacturer, drum number
  • Length / Start point / End point / Installation reference
  • Tests performed: continuity, insulation resistance, identification, polarity where applicable, joint verification where applicable
  • Test equipment: instrument, model, serial number, calibration certificate
  • Result: pass / fail / retest required
Consolidates the TEST-01 Insulation Resistance and TEST-02 Continuity results for a single cable into one certified record.
TEST-04 Earth Resistance Test Report Test Report
Purpose

To record measurement of earth resistance at designated earthing points.

Key Fields
  • Earth point ID / Equipment-system / Location / Earth electrode-reference
  • Date / Test method / Test instrument / Instrument ID / Calibration certificate
  • Test condition / Measured resistance / Acceptance criterion / Result
  • Assessment: compliant, non-compliant, investigation required, improvement required
TEST-05 Earth Continuity Test Test Report
Purpose

To verify continuity of protective earthing and bonding connections.

Key Fields
  • Equipment / Equipment ID / Earth conductor / Earth connection / Bonding point / Test point
  • Instrument / Test method / Measured value / Acceptance criterion
  • Pass/Fail / Remarks
TEST-06 Series Circuit Test Test Report
Purpose

To verify electrical continuity and performance of the AGL series circuit.

Key Fields
  • Circuit ID / Runway-Taxiway / CCR ID / Number of fixtures / Cable length / Transformer count / Circuit configuration
  • Circuit current / Circuit voltage / Insulation condition / Continuity
  • Current stability / Step-intensity response
  • Result: pass, fail, abnormal condition, further investigation
Draws directly on TEST-01 Insulation Resistance, TEST-02 Continuity, TEST-08 Current Test and TEST-11 CCR Test Report for the same circuit.
TEST-07 Voltage Test Test Report

To document voltage measurements at defined AGL test points.

Key Fields

  • Instrument / Measurement condition / Acceptance range / Result
  • Typical test locations: CCR input, CCR output, transformer primary, transformer secondary, equipment/control supply, ALCMS/control supply
TEST-08 Current Test Test Report
Purpose

To verify current at defined AGL circuits/equipment.

Key Fields
  • Circuit ID / CCR ID / Intensity step / Expected current / Measured current
  • Instrument / Test condition / Acceptance criterion / Result
  • Assessment: current stable, current abnormal, regulation issue, further testing required
TEST-09 Load Test Test Report
Purpose

To verify electrical loading of AGL circuits and equipment under defined operating conditions.

Key Fields
  • Equipment/circuit / Rated load / Connected load / Operating condition
  • Voltage, current, power, power factor where applicable, duration, temperature/ambient condition where relevant

TEST-10 Connector Test Test Report
Purpose

To verify electrical integrity and correct connection of AGL connectors.

  • Result: pass, fail, rework, replacement

TEST-11 CCR Test Report Test Report
Purpose

To document complete testing of Constant Current Regulators.

Key Fields
  • CCR ID / Manufacturer / Model / Serial number / Rating / Circuit / Location / Drawing reference
  • Pre-test: visual inspection, connections, earthing, control wiring, input supply, output circuit, calibration/test equipment
  • Functional tests: energization, output current, current regulation, intensity steps, step transition, alarm functions, protection functions, local/remote control, communication, monitoring
  • Test table: step, expected current, actual current, tolerance/requirement, result (typically 5 intensity steps)
  • Final result: pass, conditional, fail, retest required
Feeds TEST-06 Series Circuit Test and TEST-16 ALCMS Test Report, where CCR control and status are verified end to end.

  • Tests: visual inspection, continuity, insulation resistance, voltage ratio where required, primary-side verification, secondary-side verification, connection verification
  • Result: pass, fail, retest

  • Result: operational, defective, adjustment required, replacement required
TEST-14 PAPI Test Report Test Report

Key Fields

  • Documentation: survey/reference data, test equipment, test results, photographs, corrective action
  • Final result: pass, adjustment required, fail, retest
TEST-15 Sign Test Report Test Report

  • Result: pass, fail, repair required, replacement required
TEST-16 ALCMS Test Report Test Report
Purpose

To verify AGL control, monitoring, communication and alarm functions.

  • Test matrix: function (CCR control, intensity, alarm, feedback, communication), expected result, actual result, status

3 of 3 forms
TEST-23 FAT Report Acceptance Report
Purpose

To document Factory Acceptance Testing before equipment is released for shipment/site installation.

Key Fields
  • Equipment / Manufacturer, model, serial number / PO / Project / Specification / Approved datasheet
  • FAT preparation: approved FAT procedure, test equipment, calibration certificates, approved drawings, inspection checklist, test instruments
  • FAT tests (as applicable): visual inspection, dimensional verification, nameplate verification, electrical, functional, protection, control, communication, alarm, performance tests
  • Result: pass, pass with comments, fail, retest required
  • Punch list: item, observation, responsibility, target date, closure
TEST-24 SAT Report Acceptance Report
Purpose

To document Site Acceptance Testing after equipment has been installed at the project site.

Key Fields
  • Project / Airport / Location / Equipment / Equipment ID / Manufacturer, model, serial number / FAT reference
  • Installation verification: installation complete, connections complete, earthing complete, cable identification complete, approved drawings available, test equipment calibrated
  • SAT tests: power-up, functional operation, electrical tests, control tests, communication, alarm, monitoring, interface, performance, system integration
  • Result: accepted, accepted with punch points, rejected, retest required
References the TEST-23 FAT Report for the same equipment, closing the factory-to-site testing loop.
TEST-25 Functional Test Report Test Report
Purpose

To verify that an installed AGL system or equipment performs its intended operational functions.

Key Fields
  • Project / System / Equipment / Equipment ID / Circuit / Date / Test team / Test procedure
  • Functional test matrix: energization, de-energization, intensity control, local control, remote control, alarm, monitoring, communication, fault indication — expected result, actual result, status, remarks
  • Final result: functional, functional with observations, non-functional, retest required
Closes the division — a completed Functional Test Report is the standard prerequisite for the Division 07 Commissioning package.

Frequently Asked Questions

Quick answers about the 25 Division 06 Testing forms, how they are grouped, and how they connect to the rest of the library.

Q1What is Division 06 — Testing Forms in the AGL Engineering Forms & Templates library?

Division 06 is a set of 25 testing forms (TEST-01 to TEST-25) in the AGL Engineering Forms & Templates library. It is the formal testing and test-evidence layer for AGL, with every insulation resistance value, CCR step, transformer check, cable, earth, photometric measurement and factory or site acceptance test recorded against an acceptance criterion. The forms are grouped into 4 categories: Electrical Testing, Equipment Testing, Photometry and Factory / Site Testing.

Q2Which forms are included in Electrical Testing?

Electrical Testing (10 forms): TEST-01 Insulation Resistance Test Report, TEST-02 Continuity Test Report, TEST-03 Cable Test Report, TEST-04 Earth Resistance Test Report, TEST-05 Earth Continuity Test, TEST-06 Series Circuit Test, TEST-07 Voltage Test, TEST-08 Current Test, TEST-09 Load Test, TEST-10 Connector Test.

Q3Which forms are included in Equipment Testing, Photometry and Factory / Site Testing?

Equipment Testing (7 forms): TEST-11 CCR Test Report, TEST-12 Isolation Transformer Test Report, TEST-13 Fixture Test Report, TEST-14 PAPI Test Report, TEST-15 Sign Test Report, TEST-16 ALCMS Test Report, TEST-17 Approach Light Test Report; Photometry (5 forms): TEST-18 Photometric Test Report, TEST-19 Light Intensity Test Record, TEST-20 Colour Measurement Record, TEST-21 Beam Alignment Record, TEST-22 Photometric Compliance Sheet; Factory / Site Testing (3 forms): TEST-23 FAT Report, TEST-24 SAT Report, TEST-25 Functional Test Report.

Q4What is the difference between inspection and testing in the AGL forms library?

Division 05 proves the condition observed during inspection, while Division 06 proves the measured technical performance through testing. The two are cross-referenced through the Asset ID, Circuit ID, Equipment ID, Test Report No., Inspection No. and Defect/NCR No., so a completed test package feeds directly into commissioning, maintenance and the asset-lifecycle record.

Q5What is the difference between the FAT Report, the SAT Report and the Functional Test Report?

The FAT Report (TEST-23) documents Factory Acceptance Testing before equipment is released for shipment and site installation. The SAT Report (TEST-24) documents Site Acceptance Testing after the equipment has been installed at the project site. The Functional Test Report (TEST-25) verifies that an installed AGL system or equipment performs its intended operational functions.

Q6Can the forms in Division 06 be downloaded and filled in?

Yes. Each form has a Download as Word button that produces an uncontrolled sample Word template with letterhead, a document-control block, ruled entry fields and a three-tier approval table, ready to print or fill on-screen. The forms can also be searched by keyword or form ID.

Q7How do the Division 06 test reports connect to the rest of the project record?

A test report here references the installation record it is validated against, complements the condition evidence from inspection with measured performance, and carries the identifiers (Asset ID, Circuit ID, Equipment ID, Test Report No.) that let it be found from commissioning, maintenance and the asset-lifecycle record.
