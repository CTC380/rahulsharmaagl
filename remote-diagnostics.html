What are remote diagnostics?

Reading a CCR and its circuit from the control room — live values, trends and logs — so a problem is understood, and a site visit prepared, before anyone goes to the airfield.

The Fact Diagnostics

Remote diagnostics means examining the lighting equipment from the control room instead of walking the airfield. The control system’s link to each CCR and field unit carries live values (current, voltage, load, temperature, earth leakage), trends, settings and the event log, so an engineer can see how the equipment is behaving, and how it has behaved, before going anywhere.

The strongest use is trends. A reading inside its limits looks healthy, but one that climbs steadily towards its limit, such as earth leakage or CCR temperature, shows a problem developing and can be planned for before it trips. The limits are just as important: remote data shows symptoms, not damage, so the cause is still confirmed on site. Remote actions are different from remote reading. A remote command or reset can energise a circuit, so it must never be sent unless the field is confirmed safe; local mode and isolation at the equipment protect anyone working there.

  1. Connect. Access the CCR or field unit through the control system, with the right authority.
  2. Read. Look at live values, then the trend and event log behind them.
  3. Assess. Decide what the pattern suggests and what only a site visit can confirm.
  4. Prepare. Plan the visit: what to check, which tools and spares, what to isolate.
  5. Act safely. Do anything that changes the equipment only when the field is confirmed safe.

FAQ

Frequently Asked Questions

Q1What are remote diagnostics?

Examining the lighting equipment from a distance through the control system's link to the CCRs and field units. Engineers read live values, trends, settings and event logs without going to the airfield.

Q2What data can be read remotely?

Typically output current, output voltage, load, temperature, earth leakage, selected step, mode, alarms and the event log. Which items are available depends on the CCR, field unit and control system.

Q3What are the benefits?

Fewer unnecessary field visits, faster first assessment, and better-prepared visits where the engineer arrives knowing what to check and what parts or test equipment to bring. Trends can also show a developing fault before it causes an outage.

Q4What can remote diagnostics not do?

They cannot see physical problems such as a flooded base, a loose connector or a worn fixture. They show symptoms and trends, so the cause is still confirmed by testing and inspection on site.

Q5Is it safe to reset or switch a CCR remotely?

Only when the field is confirmed safe. A remote command can energise a circuit, so it must never be sent while anyone may be working on it. Isolation and lockout at the equipment, and the local or remote mode, protect people, and remote access needs authority and security controls. A remote off indication is not proof that a circuit is dead, so isolation is still proved at the equipment.

Q6Why do trends matter more than a single reading?

A single value inside its limits looks fine. A value that climbs steadily towards its limit, such as earth leakage or CCR temperature, shows a problem developing, which can be planned for before it trips.
