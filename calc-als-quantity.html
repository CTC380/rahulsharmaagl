Calculator #06

Approach Lighting System

Station generation, centreline/crossbar/side-row/SFL quantity, geometry validation and compliance dashboard for an approach lighting system (ALS).

About this calculator

This calculator does not maintain an ALS type database — it does not select ALSF-2, MALSR, SSALR, or a specific ICAO configuration for you, and it does not derive required length or station spacing from approach category alone. Those numbers are figure- and system-specific and must come from the applicable approved specification. What this calculator does is take the station spacing, required/available length, and per-station component pattern you enter, and turn them into a validated station schedule, quantity summary, and compliance dashboard — the same generic station-and-shared-fixture discipline as the earlier calculators, applied to a longer and more complex system.

Methodology

How This Calculator Works

The key design principle: this calculator does not compute ALS quantity from approach length alone. Different ALS configurations have different geometry and component counts, and this tool does not maintain a database of those configurations — it turns whatever station pattern you specify into a validated schedule and quantity summary.

Station reference

APPROACH AREA │ ▼ ●───●───●───●───●───●───● │ │ THRESHOLD (d = 0) ▼ ═══════════════════════════════ RUNWAY d increases outward from the threshold into the approach area.

Generic station engine

xi = x0 + i·S   →   N = ⌊(Lavailable − x0) / S⌋ + 1

Stations are generated across the available (physically constructible) length, referenced to the runway threshold at d = 0 — the same coordinate convention used in Calculator #05, so the two calculators' threshold references stay consistent.

Components are counted separately, then summed

Qtotal = QCL + Qcrossbar + Qside + QSFL

A crossbar is not one fixture — it is a station property containing multiple lights (2 × lights-per-side here). Side-row lights apply only across the configured station range and side-row mode. Sequenced flashing lights are never merged into the steady-burning count, since they use different equipment, control circuits, and serviceability logic.

Required vs. available length

The calculator never assumes a shortened available length is equivalent to the full nominal system. If available length is less than required length, the configuration is flagged for review rather than silently treated as compliant.

Dual-direction runways

ALS-A and ALS-B are separate systems and are never assumed identical, even on the same runway. This calculator computes one direction per session by design — running it twice, once per threshold, keeps that separation explicit rather than silently copying one system's geometry onto the other.

What this calculator does not do

It does not select an ALS type (ALSF-1, ALSF-2, MALSR, SSALR, an ICAO Annex 14 precision/simple approach lighting configuration, or any other named system) from approach category. It does not derive required length, station spacing, or crossbar dimensions from that selection. Those are figure-specific values that must come from the approved specification for the named system — entering a label in "ALS Type / Designation" is documentation only.

Obstacle-limited designs

Marking the approach area "Restricted" never produces an automatic approval or a modified geometry — it always returns an engineering-review flag. This calculator does not independently approve an obstacle-limited ALS design.

Geometry validation

Three independent checks, each optional: longitudinal spacing (interval-by-interval against tolerance), centreline alignment (single measured offset against a standard-specific tolerance you supply), and crossbar symmetry (|DL − DR| against tolerance, per crossbar). None of these tolerances are hard-coded — this calculator does not assume a universal value across standards.

Connection to Calculator #05

ALS geometry sits outward from the threshold; runway threshold/runway-end lighting sits at and beyond it. Both calculators use the same d = 0 threshold reference so a combined layout schedule stays internally consistent.

FAQ

Approach Lighting System (ALS) Quantity Calculator: Frequently Asked Questions

Quick answers on station generation, quantities and validation for an approach lighting system.

What does the ALS Quantity Calculator do?

It takes the station spacing, required and available length, and per-station component pattern that you enter, and turns them into a validated station schedule, a quantity summary and a compliance dashboard. It does not maintain an ALS type database. It does not select ALSF-2, MALSR, SSALR or a specific ICAO configuration for you, and it does not derive required length or station spacing from approach category alone.

Why must I enter the geometry myself?

Those numbers are figure- and system-specific and must come from the applicable approved specification. The design standard selection and the ALS type name only label the report. The tool does not mix ICAO and FAA geometry internally, and it does not infer whether an ALS is required from category or RVR.

How are the stations generated?

Station positions are the first station distance plus the station number times the spacing, measured from the threshold at distance 0. The number of stations is the available length minus the first station distance, divided by the spacing, rounded down, plus one. Stations are generated up to the lesser of the required and available lengths, so surplus land is never counted as lit.

How is the quantity calculated?

The total is the centreline lights, plus the crossbar lights, plus the side-row lights, plus the sequenced flashing lights. A crossbar is a station property with two times the lights per side, symmetrical about the centreline. Side-row lights apply only across the configured station range and side-row mode. Steady-burning and flashing units are kept separate, because they have different equipment, control circuits and serviceability requirements.

What happens if the available length is short or the area is restricted?

If the available length is less than the required length, the configuration is flagged for review and a length deficit is shown, and it is never silently treated as compliant. Marking the approach area Restricted never produces an automatic approval or a modified geometry, and always returns an engineering-review flag.

How are both approach directions handled?

ALS-A and ALS-B are separate systems and are never assumed identical, even on the same runway. The calculator computes one direction per session, so run it again with the other threshold's parameters. The threshold reference is the same as in Calculator #05, so a combined layout schedule stays consistent.

What field checks does it offer?

There are three optional checks. Longitudinal spacing is checked interval by interval against the nominal spacing plus or minus a tolerance, centreline alignment compares one measured offset against a tolerance you supply, and crossbar symmetry compares the left and right extents of each crossbar against a tolerance. None of these tolerances is hard-coded, because they are standard-specific.

Is the result a final design or BOQ?

No. It gives calculated nominal quantities and not a final BOQ quantity. Final approach-lighting design must be verified against the approved aerodrome lighting layout, applicable regulatory requirements, obstacle limitations and project specifications.
