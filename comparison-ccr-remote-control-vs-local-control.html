Local Control VS Remote Control

Two ways of operating the same Constant Current Regulator. Local control puts the operator at the CCR itself, switching and adjusting it directly. Remote control moves that command to a separate location — a control tower or ALCMS system — through a control/communication interface. Same regulator, two very different command paths.

02 · Definitions

What Is Local Control & What Is Remote Control?

Local Control

CCR Local Control means the Constant Current Regulator is operated directly at the CCR/equipment location — the operator selects intensity and switches the regulator using its own local switches, HMI or control panel.

Where it happens

Typically inside the electrical room or substation housing the CCR itself.

Remote Control

CCR Remote Control means the CCR is operated from a separate control location, such as an airfield lighting control panel or a control tower system, through a control/communication interface.

Where it happens

Typically from the control tower or operations centre, away from the physical CCR.

04 · The Main Difference

Control At the CCR vs Control Away From It

Local Control

The operator is physically at the CCR and switches it directly — no intermediate signal path, simplest possible arrangement.

Remote Control

The operator is away from the CCR and issues a command that travels through a control/communication interface before reaching the regulator.

Easy memory: Local = control HERE, at the equipment. Remote = control FROM ELSEWHERE, through a signal path.

05 · What Can Be Controlled

Typical Remote Control Functions

Depending on the installed CCR and the airfield control system architecture, remote control may allow functions such as:

  • ON/OFF switching
  • Lighting intensity selection
  • Circuit selection
  • Status indication
  • Fault/alarm indication
  • Equipment monitoring

The exact functions available depend entirely on the CCR model and the control system it is connected to — this should always be verified against the specific equipment and system design rather than assumed.

06 · Why Remote Control Is Useful

An airport may have numerous lighting circuits and CCRs. With local-only control, personnel would need to operate each regulator individually. A centralized remote system lets one control point command several CCRs together.

07 · Local as Fallback

Local Control During Remote-System Failure

A well-designed system may provide local control as a fallback for when the remote path is unavailable, so the CCR can still be operated even if the control tower link or communication interface is down.

Not guaranteed by default. Whether this fallback exists — and how it is arranged — depends entirely on the specific equipment and system design. It should never be assumed without confirming the actual control architecture installed.

08 · Operational Roles

Local Control vs Remote Control in Practice

Local Control — Best For

  • Testing
  • Commissioning
  • Troubleshooting
  • Maintenance work at the regulator

Direct access at the CCR makes it the natural mode for hands-on technical work.

Remote Control — Best For

  • Day-to-day operational control
  • Status monitoring
  • Centralized management of multiple CCRs

The command system view makes it the natural mode for routine airfield lighting operation.

09 · Safety & Interlocking

Interlocks and Status Feedback

Remote operation may incorporate interlocks and status feedback, so a command sent from the tower is checked before it is applied and the achieved state is reported back to the control centre.

10 · Common Misconceptions

Myths vs Facts

Myth: Remote control replaces local control entirely
Fact

Not necessarily. Many systems retain local control as a fallback or for maintenance access — whether it does depends on the installed design.

Myth: Local control is obsolete on a modern airfield
Fact

No. Local control remains essential for testing, commissioning and troubleshooting, even on airfields with full remote/ALCMS control.

Myth: Remote control means a different CCR
Fact

No. It's the same regulator — remote and local control describe how it is commanded, not what equipment it is.

Myth: Every CCR supports the same remote functions
Fact

No. Available remote functions depend on the specific CCR model and the control system it is interfaced with.

12 · Engineering Verdict

Local Control vs Remote Control

Engineering Verdict

Local and remote control are not competing options — they are two operating modes of the same regulator, and most airfield lighting installations are designed to use both. Remote control gives centralized, coordinated operation from the tower or ALCMS; local control gives the direct, unambiguous access that testing, commissioning and troubleshooting depend on.

Neither mode changes what the CCR is — only how, and from where, it is commanded. Whether local control survives as a fallback when the remote link fails depends entirely on the specific system design and must always be confirmed rather than assumed.

LocalControl at the CCR, direct path, best for hands-on work.
RemoteControl away from the CCR, via interface, best for centralized operation.

Local = direct equipment control. Remote = centralized operational control. A well-designed installation gives you both.

13 · FAQ

Frequently Asked Questions

What is the core difference between CCR local and remote control?

Local control means the CCR is operated directly at the regulator itself. Remote control means it is operated from a separate location, such as a control tower, through a control/communication interface.

Does remote control replace local control?

Not automatically. A well-designed system may retain local control as a fallback for when the remote path is unavailable, but this depends on the specific equipment and system design.

What functions can typically be controlled remotely?

Depending on the CCR and control architecture, remote control may allow ON/OFF switching, intensity selection, circuit selection, status indication, fault/alarm indication and equipment monitoring.

Why use remote control if local control already works?

An airport can have numerous CCRs. Local-only control requires operating each one individually; a centralized remote system lets one control point coordinate several CCRs at once.

Is local control still used once remote/ALCMS control is in place?

Yes. Local control remains the standard mode for testing, commissioning, troubleshooting and maintenance access, even on airfields with a full remote control system.

What role do interlocks play in remote control?

Interlocks and status feedback help prevent inappropriate operation and let the operator confirm whether a remote command actually achieved the intended state at the CCR.

14 · Standards & Reference Basis

Governing Documents

For an actual project design, always verify the current edition of the applicable documents.

ICAO Annex 14, Volume I

Aerodrome Design and Operations — requirements for control of aeronautical ground lighting, including selective switching and intensity control from the aerodrome control tower.

FAA Advisory Circulars

Design and installation guidance for CCR control systems, including local panel control and remote/ALCMS interfacing at civil airports.

IS 12291

Indian standard: Specification for Constant Current Regulators for Airport Lighting Systems — applicable to CCR construction, local control panels and remote-control/monitoring interfacing on Indian airport projects.

Final Engineering Note

Do not assume a CCR's remote functions or local fallback from a generic reference. The actual control architecture must always be confirmed from the equipment documentation, the approved airfield lighting control system design and project-specific requirements.

Local control is not a lesser mode kept only for emergencies, and remote control is not simply "the modern option." Each exists because the airfield needs both direct equipment access and centralized operational command.
