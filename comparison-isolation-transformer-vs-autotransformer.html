Isolation Transformer VS Autotransformer

An isolation transformer has electrically separate primary and secondary windings, coupled only magnetically, so there is no direct conductive path between input and output. An autotransformer uses a single common winding with a tap, so the primary and secondary share a direct electrical connection. For AGL, this distinction matters because the isolation transformer is what provides the required electrical separation between the series circuit and each individual light fixture.

02 · Definitions

What Is an Isolation Transformer & an Autotransformer?

Isolation Transformer

An isolation transformer has two electrically separate windings. Power crosses from primary to secondary only through the magnetic field in the core — there is no direct electrical connection between the two sides.

Main characteristics

  • Separate primary and secondary windings
  • Coupling by magnetic field only
  • Provides galvanic isolation
  • Suitable for AGL individual fixture isolation

Autotransformer

An autotransformer uses one continuous winding with one or more taps. Part of the winding is common to both input and output, so the input and output are electrically connected.

Main characteristics

  • Single continuous winding with a tap
  • Direct conductive path input to output
  • No galvanic isolation
  • Typically smaller and more efficient for the same rating

05 · Galvanic Isolation

The Most Important Distinction

Galvanic isolation — whether there is any direct conductive path between input and output — is the single most important distinction between the two transformer types.

Isolation Transformer

Galvanically isolated

Input and output are linked only by the magnetic field; no conductive path exists between the two sides.

Autotransformer

Not galvanically isolated

A section of the common winding directly connects input and output, so a conductive path exists between the two sides.

06 · Why This Matters in AGL

The Role of Isolation in an AGL Series Circuit

A typical AGL series arrangement runs from the CCR, through the series circuit, through an isolation transformer, to the individual light fixture. The transformer's job is to interface the series circuit with each fixture while keeping the fixture electrically separated from the series circuit.

Simplified architecture: CCR → Series Circuit → AGL Isolation Transformer → Individual Light. The isolation transformer provides the electrical separation expected between the series circuit and each individual fixture.

Because an autotransformer keeps a direct conductive path between its primary and secondary sides, it cannot simply replace an AGL isolation transformer where galvanic isolation is required.

08 · Voltage Transformation

Both Types Can Transform Voltage

Voltage transformation alone does not distinguish the two types — both an isolation transformer and an autotransformer can step voltage up or down. The isolation transformer does this across two separate windings; the autotransformer does it across one common winding with a tap.

The critical distinction is not voltage transformation itself — it is whether the input and output are electrically isolated from one another.

09 · Size & Copper Requirement

Construction and Material Trends

Isolation Transformer

Requires fully separate primary and secondary windings, which generally means more winding material and a larger, heavier unit for the same rating.

Autotransformer

Part of the winding is shared between primary and secondary, so an autotransformer can generally be smaller and lighter than an isolation transformer of the same apparent power.

This is a general construction trend rather than a fixed rule for every particular transformer design.

10 · Efficiency

Efficiency Considerations

Both transformer types can achieve high efficiency. Autotransformers often have an efficiency advantage because less winding material and fewer associated losses are involved for the same rating.

For AGL, electrical isolation is more important than simply maximising transformer efficiency. A more efficient autotransformer is not an acceptable substitute where galvanic isolation is the required function.

13 · Advantages

Where Each Type Wins

Advantages of Isolation Transformer

  • Provides galvanic isolation between input and output
  • Suits AGL individual-fixture isolation from the series circuit
  • Adds a barrier that limits primary-side conditions reaching the secondary
  • Standard choice for safety-isolation applications

Advantages of Autotransformer

  • Generally smaller and lighter for the same rating
  • Lower copper/material requirement
  • Often a very high efficiency for the same rating
  • Economical for motor starting and general voltage adjustment
14 · Do Not Confuse

Voltage Transformation vs Electrical Isolation

Do not equate "transforms voltage" with "provides isolation." Both transformer types can transform voltage, but only the isolation transformer provides galvanic isolation between its two sides — a distinction that matters directly in AGL, where the individual fixture must be electrically separated from the series circuit.

16 · Common Misconceptions

Myths vs Facts

Myth: Any transformer that changes voltage provides isolation
Fact

Voltage transformation and galvanic isolation are separate properties. An autotransformer changes voltage using a common winding, but the direct conductive path it retains means it does not provide galvanic isolation.

Myth: An autotransformer is simply a smaller isolation transformer
Fact

The two use fundamentally different winding arrangements. The autotransformer's smaller size for the same rating comes from sharing part of the winding between primary and secondary — the same feature that removes galvanic isolation.

Myth: Isolation transformers and autotransformers are interchangeable in AGL circuits
Fact

Where the AGL design calls for galvanic isolation between the series circuit and the individual fixture, an autotransformer's direct conductive path does not meet that requirement — the two are not interchangeable for that function.

17 · Engineering Selection

Choosing Between the Two

When selecting or interpreting a transformer's role in an AGL or general electrical circuit, consider:

  • Whether galvanic isolation between input and output is a functional or safety requirement
  • Whether the application is series-circuit AGL fixture isolation or general voltage adjustment
  • Size, weight and material constraints for the installation
  • Cost versus the value of the isolation barrier for the application
  • Applicable ICAO/national AGL requirements for isolation transformers
  • Manufacturer datasheets and rated primary/secondary currents
  • Fault and safety behaviour required for the specific circuit
  • Airport-specific technical specifications
18 · Engineering Verdict

Which Type Applies Where?

Engineering Verdict

An isolation transformer has separate primary and secondary windings, coupled only magnetically, giving it galvanic isolation — this is the type used to interface an AGL individual light fixture with the series circuit. An autotransformer uses one common winding with a tap, giving a direct conductive connection between input and output — economical for voltage adjustment, but not suitable where AGL-style galvanic isolation is required.

The final selection for an actual airport project should always be based on the applicable current ICAO/national AGL standard, the approved circuit design and the isolation transformer/equipment datasheets — not on a generic comparison alone.

19 · FAQ

Frequently Asked Questions

What is the main difference between an isolation transformer and an autotransformer?

An isolation transformer has separate primary and secondary windings coupled only magnetically, giving galvanic isolation. An autotransformer has a single common winding with a tap, so input and output share a direct electrical connection.

Why does AGL use an isolation transformer rather than an autotransformer?

The individual light fixture needs to be electrically separated from the AGL series circuit. An isolation transformer's separate windings provide that separation, while an autotransformer's shared winding keeps a direct conductive path between the two sides.

Can an autotransformer replace an isolation transformer in an AGL circuit?

Not where galvanic isolation is required. An autotransformer retains a direct conductive path between input and output, which defeats the isolation function expected of an AGL isolation transformer.

Do both transformer types transform voltage?

Yes. Both can step voltage up or down. The key difference is not voltage transformation itself, but whether the input and output remain electrically isolated.

Why are autotransformers often smaller than isolation transformers of the same rating?

Part of the winding is common to both primary and secondary in an autotransformer, which generally means less winding material is needed compared with the fully separate windings of an isolation transformer.

Is an autotransformer more efficient than an isolation transformer?

Autotransformers often have an efficiency advantage due to lower winding material and associated losses. For AGL, however, electrical isolation is the more important requirement than maximising efficiency alone.

Where are autotransformers typically used instead of isolation transformers?

Autotransformers are common for motor starting, general voltage adjustment and power systems where galvanic isolation between input and output is not a functional requirement.
