Calculator #02

Runway Light Quantity

Nominal fixture-quantity tool for a full runway lighting configuration — edge, threshold, wing-bar and runway-end lights, calculated as separate components rather than one merged total.

About this calculator

Runway edge-light quantity reuses Calculator #01's validated spacing engine. Threshold-light quantity is split by operational category — a fixed minimum for non-instrument/non-precision runways, and a geometry-based calculation from the edge-light-row span for CAT I/II/III. Runway-end lights are shared with threshold fittings where the threshold sits at the runway extremity, and treated as a separate component where the threshold is displaced. Wing-bar and displaced-threshold runway-end quantities are entered against the approved layout rather than derived from a generic formula, since ICAO's figure-level endpoint arrangement is not reproduced here.

Method & Reference

How This Calculator Works

Runway lighting quantity is broken into separate components rather than one merged total — ICAO treats runway edge lights, threshold/wing-bar lights, and runway-end lights as distinct provisions with different spacing rules.

Edge-light quantity (inherited from Calculator #01)

For design length L against maximum interval Smax, rounding up (never ordinary rounding, since any excess is a non-compliance):

N = ⌈ L / Smax ⌉  →  Pside = N + 1  →  Ptotal = 2(N + 1)

This calculator reuses the same spacing engine as Calculator #01 so the two tools cannot silently disagree on the edge-light count for the same runway.

Non-instrument / non-precision threshold

ICAO 5.3.10 sets a fixed minimum of 6 threshold lights where threshold lights are required. Where the threshold is displaced and wing-bar lights are provided, the displaced-threshold + wing-bar configuration can remove the threshold-light requirement entirely — this calculator applies that exception only when both conditions are selected, and never infers it from one alone.

Precision CAT I / II / III threshold geometry

The threshold-light count is tied to the edge-light-row span WE and the maximum spacing criterion (3 m by default):

NT = ⌈ WE / Smax,T ⌉  →  QT = NT + endpoint adjustment

The endpoint adjustment is deliberately not hard-coded. Whether the final fixture count is NT, NT + 1, or another figure-specific value depends on whether both edge-light-row endpoints carry a fixture, whether a centreline position exists, and the exact arrangement in the applicable standard figure (see the applicable ICAO Annex 14 figure). This calculator defaults to +1 but exposes the setting so it is never a hidden assumption.

Runway-end lights — shared or separate

ICAO 5.3.11 requires runway-end lights for a runway equipped with edge lights, but permits fittings serving as threshold lights to also serve as runway-end lights when the threshold is at the runway extremity. This calculator applies that sharing logic automatically when the threshold is not displaced (no additional fixtures added), and treats runway-end lighting as a separate, user-entered component whenever a threshold displacement is selected — since a displaced threshold makes threshold lighting and runway-end lighting distinct geometric elements.

Wing bars are not "extra edge lights"

A wing bar is a separate threshold-lighting arrangement, not simply additional runway edge lights, and its exact fixture count is figure-specific. This calculator asks for the wing-bar quantity directly against the approved layout rather than generating one from a generic formula.

Quantity vs. serviceability

This calculator produces an installed fixture quantity. It does not multiply that quantity by a serviceability percentage (the percentages in the maintenance provisions of the governing standard) — quantity and serviceability are separate calculations and should not be combined here.

FAQ

Runway Light Quantity Calculator: Frequently Asked Questions

Quick answers on how the calculator counts edge, threshold, wing-bar and runway-end lights.

What does the Runway Light Quantity Calculator do?

It works out a calculated nominal fixture quantity for a runway, split into edge lights, threshold lights, threshold wing-bar lights and runway-end lights. These are kept as separate components because ICAO treats them as distinct provisions with different spacing rules.

How are runway edge lights counted?

The number of intervals is N = ⌈L ÷ Smax⌉, rounded up because any excess spacing is a non-compliance. That gives N + 1 positions per side and 2(N + 1) edge lights in total. The maximum spacing follows the design standard and runway classification you select. The same spacing engine is used as in Calculator #01, so the two tools cannot disagree on the edge-light count.

How many threshold lights does a non-instrument or non-precision runway need?

ICAO 5.3.10 sets a fixed minimum of 6 threshold lights where threshold lights are required. If the threshold is displaced and wing-bar lights are provided, that configuration can remove the threshold-light requirement. The calculator applies this exception only when both conditions are selected, and never infers it from one alone.

How are CAT I, II and III threshold lights calculated?

The threshold-light count is tied to the edge-light-row span WE, which is the runway width plus twice the edge-light offset. The interval count is NT = ⌈WE ÷ Smax,T⌉, with a default maximum spacing of 3 m, and the fixture count is NT plus an endpoint adjustment. For example, WE = 30 m gives 10 intervals at 3.00 m.

Why is the endpoint arrangement a setting I have to choose?

Whether the final fixture count is NT, NT + 1 or another figure-specific value depends on whether both edge-light-row endpoints carry a fixture and on the exact arrangement in the applicable standard figure. The calculator defaults to +1 but exposes the setting so it is never a hidden assumption. Confirm it against the applicable ICAO Annex 14 figure.

Are runway-end lights counted separately from threshold lights?

It depends on the threshold. ICAO 5.3.11 permits fittings that serve as threshold lights to also serve as runway-end lights when the threshold is at the runway extremity, so no additional fixtures are added in that case. With a displaced threshold, the runway-end lights become a separate element and their quantity is entered per the approved layout.

Which design standard should I select for an Indian project?

The design-basis order is the project specification or approved drawing, then the applicable DGCA requirement, then ICAO Annex 14 where adopted, and FAA only where the project specification calls for it. Select DGCA / Indian or Project-Specific rather than assuming an ICAO or FAA default applies. DGCA and AAI projects generally follow the ICAO table unless the approved project specification says otherwise.

Can I use the result as the final bill of quantities?

No. The result is a calculated nominal quantity, not a final BOQ quantity. It is an installed fixture count and does not include a serviceability percentage. CAT I, II and III threshold counts depend on the endpoint arrangement in the standard figure, and displaced-threshold wing-bar and runway-end quantities are entered against the project layout. Verify all figures against the approved aerodrome lighting drawing before issue.
