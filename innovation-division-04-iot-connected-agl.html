IoT & Connected AGL

The sensing, connectivity and data-acquisition layer of the AGL Innovation Hub. Division 04 connects AGL field assets to a reliable data infrastructure so that asset condition, electrical performance, environmental conditions and operational status can be continuously observed and converted into usable engineering information — the physical foundation everything from AI diagnostics to digital twins is eventually built on.

IOT-01 Smart AGL Sensors
Purpose

Develop and evaluate sensors capable of collecting useful operational and condition data from AGL equipment.

Potential Sensor Categories
  • Electrical sensors
  • Temperature sensors
  • Current sensors
  • Voltage sensors
  • Equipment-condition sensors
  • Environmental sensors
  • Vibration sensors where applicable
  • Status sensors
  • Communication-status sensors
  • Fixture-condition sensors
Sensor Data — Minimum Record

Sensor ID · Sensor type · Measurement parameter · Asset ID · Location · Measurement range · Accuracy · Sampling frequency · Communication method · Installation date · Calibration status · Health/status.

IOT-03 Wireless Monitoring
Purpose

Investigate wireless technologies for monitoring AGL assets where technically and operationally appropriate.

Areas of Study
  • Wireless sensor communication
  • Wireless equipment monitoring
  • Wireless fixture monitoring
  • Wireless environmental monitoring
  • Wireless gateways
  • Network reliability
  • Communication range
  • Interference considerations
  • Data security
  • Network redundancy
Evaluation Criteria

Reliability · Availability · Coverage · Latency · Security · Maintainability · Power requirements · Environmental suitability · Scalability.

Important Principle

Wireless technology should be treated as an engineering option, not automatically as the preferred architecture for safety-critical AGL functions.

IOT-05 Environmental Sensors
Purpose

Monitor environmental conditions that could influence AGL asset condition and performance.

Potential Parameters
  • Temperature
  • Humidity
  • Rainfall
  • Wind
  • Atmospheric conditions
  • Water-ingress indicators
  • Environmental exposure
Applications

Environmental data can be correlated with fixture failures, transformer condition, cable problems, connector degradation, corrosion, equipment temperature and failure frequency — creating an important bridge between environmental conditions and AGL reliability.

IOT-08 Current Monitoring
Purpose

Monitor electrical current associated with connected AGL equipment and circuits.

Potential Applications

CCR output · AGL circuit · Equipment load · Fixture current · Abnormal-current detection.

Possible Intelligence

Normal current profile · Abnormal current · Sudden change · Long-term trend · Current imbalance where applicable · Fault indication.

Engineering Value

Fault diagnosis · Asset health · Circuit monitoring · Energy analysis · Predictive maintenance.

IOT-12 Cable-Condition Monitoring

Connectivity Layer
Controllers, wired communication, wireless communication, sensor networks, IoT gateways.

Edge / Data Layer
Data collection, filtering, edge processing, event detection, data storage, edge-to-cloud communication.

Intelligence / Application Layer
AGL monitoring, dashboards, AI, predictive maintenance, asset health, failure analysis, energy analytics, maintenance decisions.

IoT Security & Reliability

Not separately listed among the 18 source topics, but any practical AGL IoT programme should treat these as implementation requirements rather than independent innovation topics. For safety-critical AGL functions, IoT monitoring should be architected so that a loss of connectivity does not create an unsafe dependency on the monitoring network.

Security

  • Device authentication
  • Access control
  • Data protection
  • Network security
  • Secure communications
  • Firmware/update management
  • Audit logging

Reliability

  • Communication availability
  • Gateway availability
  • Sensor availability
  • Data-loss monitoring
  • Redundancy
  • Failure recovery
  • Offline operation
  • Time synchronization
