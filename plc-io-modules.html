What are PLC I/O modules?

Plug-in cards that connect the PLC to the airfield: input modules bring status in, output modules send commands out.

The Fact Control hardware

A PLC I/O module is a plug-in card that links the PLC to the equipment it controls. Input modules turn field signals, such as a CCR status contact, a switch position, an alarm contact or a 4 to 20 mA reading, into values the CPU can read. Output modules turn the CPU's decisions into signals that drive pilot relay coils, contactors and other equipment. Digital modules handle on/off signals and analogue modules handle varying ones. The modules sit in the rack beside the CPU, or in remote racks near the equipment, linked back by the control network.

The field side is kept apart from the logic side, often by an optical isolator, so a surge or fault on a long field cable is less likely to reach the CPU. Each channel usually has an LED that shows its state, which makes fault-finding quick. The signal must match the module: a wrong voltage or signal type can damage the module or give a false reading. Field wiring can stay live with the PLC off, so isolate and prove dead before touching terminals. The PLC reads the inputs, runs its program and writes the outputs in each scan, and a relay cabinet often sits between an output module and the equipment it commands.

FAQ

Frequently Asked Questions

Q1What is a PLC I/O module?

A plug-in card in the PLC rack that connects the controller to the field. An input module turns a field signal, such as a CCR status contact or a 4 to 20 mA reading, into a value the CPU can read. An output module turns the CPU's decision into a signal that switches a relay, a contactor or other equipment.

Q2What types of I/O module are there?

Digital modules handle on/off signals and analogue modules handle varying signals such as 4 to 20 mA or 0 to 10 V. Each comes as an input or an output type. Special modules also exist for communications, counting and temperature. In an AGL system the I/O may sit in the main rack or in remote racks near the equipment, linked back by the control network.

Q3Why are the modules isolated from the CPU?

Field cables run a long way across the airfield and can pick up surges and faults. Most modules separate the field side from the logic side, often with an optical isolator, so a fault on the wiring is less likely to reach the CPU. Isolation helps but does not replace proper earthing and surge protection.

Q4How do I/O modules fit the PLC scan cycle?

Typically the PLC copies the inputs into memory at the start of a scan, runs the program on that snapshot, then writes the results out to the output modules. An output therefore changes at the end of a scan, not the instant the program decides it. The manufacturer's data gives the response time of each module type.

Q5What should be checked on PLC I/O modules?

That each channel's LED matches the real state in the field; that the signal type and voltage match the module; that terminals are tight and labelled; that a spare module is held; and that any forced input or output is authorised and recorded. Field wiring can stay live with the PLC off, so isolate and prove dead before touching terminals.
