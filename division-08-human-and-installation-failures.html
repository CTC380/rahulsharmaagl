Human & Installation Failures

The dedicated human-factor, installation, testing/commissioning, maintenance, documentation and competency-related failure section of the AGL Failure Database. Many AGL failures do not originate from an equipment defect — they originate from incorrect installation, incorrect testing, maintenance error, inadequate documentation, insufficient training or procedural non-compliance. Division 08 records the human/installation action that created or contributed to a failure, while separately identifying the resulting equipment failure, failure mechanism and root cause.

Initial Issue

Key principle — Record the human/installation action that created or contributed to the failure, while separately identifying the resulting equipment failure, failure mechanism and root cause. Example: incorrect connector installation → poor contact → high contact resistance → connector overheating → fixture failure.

Not a blame list — Division 08 should never become a database that simply blames personnel. Every record moves through six levels — technical failure, failure mode, failure mechanism, immediate cause, human/installation cause and system/root cause — so that “human error” is never the final answer without asking why the error occurred.

HIF-01 Incorrect Installation
Failure Definition

Installation of an AGL component, assembly or system in a manner that does not comply with the approved design, installation procedure, manufacturer's requirements or applicable project requirements.

Possible Areas
  • Fixture
  • Transformer
  • Cable
  • Connector
  • Base can
  • CCR
  • Sign
  • PAPI
  • Approach-lighting equipment
  • Control equipment
Possible Consequences
  • Premature component failure
  • Misalignment
  • Water ingress
  • Electrical fault
  • Mechanical instability
  • Poor system performance
Investigation

Compare: actual installation ↔ approved drawing ↔ installation procedure ↔ manufacturer's requirements.

D. Human Error Classification

Human error should be classified carefully so it never becomes the final RCA without investigating why the error occurred:

Action Error

Person performs the wrong action — e.g. incorrect wiring.

Omission

Required action was not performed — e.g. incomplete maintenance.

Knowledge/Competency Issue

Person lacks the required competence — e.g. inadequate training.

Procedure/Document Issue

The available instruction is wrong, unclear or outdated — e.g. incorrect revision used.

System/Management Issue

The work environment allowed or encouraged the error — e.g. inadequate document control or inadequate verification.

Why Division 08 Matters

Many AGL failures do not originate from an equipment defect — they originate from incorrect installation, incorrect testing, maintenance error, inadequate documentation, insufficient training or procedural non-compliance. This makes Division 08 a true human-factor and installation RCA division, rather than simply a list of technician mistakes, and provides the necessary connection between the technical failures recorded in Divisions 01–07 and the later RCA, maintenance, audit, competency and reliability divisions.

Frequently Asked Questions

Quick answers about human-factor, installation, testing, maintenance and documentation failures, as covered in Division 08 of the AGL Failure Database.

Q1What is Division 08 — Human & Installation Failures in the AGL Failure Database?

Division 08 covers human-factor, installation, testing and commissioning, maintenance, documentation and competency-related failures. It contains 25 published topics (HIF-01 to HIF-25), and is a human-factor and installation RCA division rather than a list of technician mistakes.

Q2How are the 25 human and installation topics grouped?

They fall into four groups: Installation Failures (10 topics), Testing & Commissioning Failures (5), Maintenance Failures (5) and Documentation & Training Failures (5).

Q3Which installation and testing failures does Division 08 cover?

Installation topics include incorrect installation, wiring, cable routing, connector installation, fixture alignment and equipment positioning, plus improper sealing, improper torque, incorrect earthing and incorrect component selection. Testing and commissioning topics include calibration error, incorrect test procedure, incorrect measurement, incorrect acceptance decision and test-equipment error.

Q4Which maintenance, documentation and training failures does Division 08 cover?

Maintenance topics include maintenance error, incorrect component replacement, incorrect troubleshooting, incomplete maintenance and improper cleaning. Documentation and training topics include documentation error, incorrect drawing, incorrect revision used, inadequate training and procedural non-compliance.

Q5Does Division 08 simply blame personnel?

No. Division 08 should not become a database that simply blames personnel. Every case is traced through six levels: technical failure, failure mode, failure mechanism, immediate cause, human or installation cause, and system or root cause. The system cause may be an incorrect procedure, inadequate training, incorrect revision, poor supervision, inadequate inspection, procedural non-compliance or a design or documentation issue.

Q6How is human error classified in Division 08?

Human error is classified so it never becomes the final RCA without investigating why it occurred. The classes are Action Error (the wrong action, such as incorrect wiring), Omission (a required action not performed), Knowledge/Competency Issue, Procedure/Document Issue (for example an incorrect revision used) and System/Management Issue (for example inadequate document control or verification).

Q7What human-to-technical failure chains does Division 08 capture?

The most valuable part of Division 08 is linking human actions to the resulting technical failure. In the connector chain, incorrect connector installation leads to poor contact, high contact resistance, connector overheating, connector failure and a fixture outage. In the cable chain, incorrect cable routing leads to mechanical stress, cable insulation damage, insulation breakdown, an earth fault and a circuit outage.

Q8Where should the investigation start for a human or installation failure?

The failure matrix gives a primary investigation for each topic. Incorrect installation is checked against the approved requirement, incorrect wiring against the wiring diagram and field wiring, incorrect cable routing against route and design verification, incorrect connector installation against connector assembly, and incorrect fixture alignment against alignment and aiming.

Q9What should be recorded for a Division 08 case?

Each case is a standard record grouped by identification (airport/project, location, asset or component, work activity, responsible activity or team), failure, human and installation information, evidence, RCA, corrective action and reliability. The recommended architecture runs from activity, failure event, technical failure mode and mechanism through human factor, contributing condition and root cause to corrective action, verification, preventive action and recurrence monitoring.
