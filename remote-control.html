What is remote control?

Remote control is operating airfield lighting from the tower or a control room, with commands travelling through the ALCMS and network to a CCR set to Remote.

The Fact Operation from a distance

Remote control means the airfield lighting is operated from somewhere other than the equipment, usually the tower HMI or a control room, through the ALCMS. The operator selects a circuit and a setting such as on, off or a brightness step and confirms it. The command goes to the ALCMS server, across the communication network to a field controller at the substation, and on to the CCR, which changes the output current of the series circuit.

The CCR only accepts these commands while its selector is in Remote. If it is in Local or Off, the command is ignored. The status returns along the same path so the screen shows what the CCR is actually doing, and alarms come back with it. A command can also be refused because of user access level, an interlock or a fault, and a failed link can leave the screen out of date, so the result is checked against the status. What the CCR does on loss of communication is set by its design and the project.

FAQ

Frequently Asked Questions

Q1What does remote control mean in airfield lighting?

Remote control means the lighting is switched and set from a distance, normally by the tower or a control room through the ALCMS. The command travels over the network to the CCR, and the status travels back.

Q2What is the path of a remote command?

The operator selects and confirms a command on the HMI. The ALCMS server processes it and sends it over the network to a field controller or PLC, which passes it to the CCR. The CCR changes the circuit and reports its state back along the same route.

Q3Why might a remote command not work?

The CCR selector may be in Local or Off, the communication link may have failed, the user may lack the access level, or an interlock or fault may block the change. The status shown on the screen should always be checked against the result.

Q4What happens to the lights if the link fails?

It depends on the CCR design and the project. A CCR often holds its last state, but this is not guaranteed. The failure flow, the airport procedure and the manufacturer documents say what is expected, and the tower must be told.

Q5How is remote control different from local control?

Both end at the same CCR. In remote the command comes from the tower or ALCMS and the selector is in Remote. In local the command comes from the panel at the CCR and tower commands are ignored.

Q6Does the tower always have to use remote control?

No. Tower staff normally use it day to day, but maintenance stations or a control room may also have remote access depending on user levels. Which stations can command, and when, is set by the project design and the airport.
