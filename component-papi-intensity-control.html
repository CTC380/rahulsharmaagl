PAPI Intensity Control

The subsystem responsible for adjusting the brightness of PAPI light units to match ambient light conditions—day, twilight, and night. Whether integrated into the Control Unit, the Constant Current Regulator (CCR), or a standalone module, intensity control ensures that the PAPI provides optimal visual contrast without blinding or being too dim for pilots.

Overview

What Is It?

The PAPI Intensity Control is the component—or set of components—that manages the luminous intensity of the PAPI light units. It receives brightness commands from the air traffic control tower, the ALCMS, or a local manual panel, and translates these commands into appropriate electrical signals to the lamps or LED modules.

Intensity control is essential because the required brightness of PAPI varies dramatically with ambient light: during bright daylight, the system must be intensely bright to be visible against the sky; at night, lower intensities are needed to avoid glare. Typically, PAPI systems support 3 or 5 intensity steps, corresponding to day, twilight, night (and intermediate levels for 5‑step systems).

The intensity control function may be implemented as:

  • Integrated into the PAPI Control Unit – as a set of relay or solid‑state outputs that switch the CCR’s current taps.
  • Part of the Constant Current Regulator (CCR) – where the CCR itself has selectable current levels, and the control unit merely sends a selection signal.
  • Standalone module – a separate device with its own user interface and communication, often used in smaller or portable installations.
Purpose

Purpose & Function

The intensity control exists because PAPI's red/white indication has to remain equally readable at both ends of an enormous range of ambient brightness, and a fixed-output light source cannot do that. In full daylight, especially against a bright sky, a dim PAPI beam simply disappears from view before a pilot ever gets useful glide slope information from it; at night, that same high output would glare and could actually make the red/white contrast harder to judge rather than easier. Its function, then, isn't brightness for its own sake but legibility — keeping the pattern equally clear and unambiguous whether it's being read at midday or on a moonless night, which is what allows a single fixed installation to serve every hour of operation rather than only a narrow band of lighting conditions.

LED‑based PAPI systems may use PWM (pulse‑width modulation) or current‑controlled drivers, but the principle of stepped brightness remains the same.

Application

Where Is It Used?

PAPI intensity control is an essential feature of every PAPI system, regardless of the installation:

  • Precision runways (CAT I, II, III) – integrated with the ALCMS for automatic brightness selection based on ambient light sensors or tower commands.
  • Non‑precision runways – often with manual step selection via a control panel in the tower or electrical room.
  • Heliports – with dedicated helicopter PAPI intensity control, possibly with different step values.
  • Military airfields – where rapid intensity changes may be needed for tactical operations.
  • Portable or temporary PAPI – using battery‑powered controllers with simple rotary switches for step selection.
  • Retrofit upgrades – where an existing PAPI with a manual switch is upgraded to an automatic system with ALCMS integration.
Placement

Installation & Location

The intensity control electronics sit in the CCR room or equipment shelter alongside the PAPI's power supply, wired into the constant current loop (or DC distribution) feeding the wing bar and, where fitted, into the ALCMS network or ambient light sensor providing automatic brightness commands. A manual control panel, where used instead of or alongside automatic control, is typically located in the tower or a nearby electrical room so controllers can select a step directly without needing shelter access. On portable PAPI, the equivalent controller is built into the unit itself with a simple rotary switch, keeping intensity selection at the fixture rather than routed back to a fixed control room. Wherever it sits, the controller's position keeps its control wiring to the CCR or driver circuit short, since that link carries the step commands that ultimately set the wing bar's brightness.

Function

How Does It Work?

The intensity control process involves several steps, from command to light output:

  • Command Generation: The desired brightness step is determined by the air traffic controller (based on weather, time of day, or pilot request) or automatically by an ambient light sensor feeding the ALCMS. The command is sent to the intensity control module.
  • Signal Translation: The intensity control module converts the command into a control signal. In a traditional system, this is typically a set of relay contacts that select the appropriate tap on the CCR’s multi‑tap transformer. In modern systems, it may be a digital signal (e.g., Modbus) to the CCR to set the output current.
  • CCR Output Adjustment: The CCR adjusts its output current to the selected value (e.g., 2.8A, 4.1A, 6.6A). This current is fed into the series circuit, and each PAPI unit receives the same current, which determines its brightness.
  • LED‑Specific Control: For LED‑based PAPI systems, the CCR may still supply a constant current (e.g., 6.6A) and the LED drivers inside each unit use PWM to adjust brightness. In this case, the intensity control module sends a PWM signal or a separate 0–10V control signal to the drivers, independent of the series current. Some LED systems use a two‑wire power and data interface, where the intensity command is embedded in the power signal.
  • Monitoring and Feedback: Advanced intensity control modules monitor the actual current or light output to verify that the correct intensity has been achieved. If there is a deviation, an alarm is generated.
Architecture

System Architecture & Control Logic

Intensity control is the command layer that sits between a brightness decision and the light actually reaching the required step. An ATC instruction, an ALCMS schedule, or an ambient light sensor generates the desired brightness step, and the intensity control module translates that into whichever signal path the installation uses — a relay selecting a CCR tap for traditional series-current systems, or a PWM/0–10V signal to LED drivers for systems that hold the series current constant and vary duty cycle instead.

Because every PAPI unit on the loop receives the same current (or the same PWM command, on LED systems), intensity is inherently a loop-wide setting rather than a per-unit one — the module's monitoring and feedback function exists to confirm that the whole array actually reached the commanded step, not to adjust any single unit independently of the rest.

Construction

Physical Construction

Where intensity control is integrated into the PAPI Control Unit, its physical form is a bank of relay or solid-state switching outputs mounted on the control unit's internal circuit board, wired to switch the CCR's current taps or a PWM driver stage in response to the selected step. Where it forms part of the CCR itself, the switching hardware sits inside the CCR's own enclosure, with the control unit reduced to sending a simple selection signal over a control cable. A standalone module takes the form of its own small sealed enclosure, housing a switching or PWM output stage, a local keypad or rotary selector for manual step selection, and a communications port for remote control, mounted either in an equipment room rack or a weatherproof field cabinet depending on the installation. In every configuration the switching components are rated for the full series-circuit current or LED driver load they carry, with heat-sinking or ventilation sized to the switching losses involved.

Field Notes

Common Field Issues

Incorrect Step Selection

Manual selection errors can result in PAPI being too bright (causing glare) or too dim (not visible). Use clear labeling and, where possible, integrate automatic ambient light sensors to reduce human error. Regular training for tower staff is essential.

Relay Contact Wear

In systems that use relays to switch CCR taps, contacts can wear out or weld shut over time, leading to incorrect current levels. Regular inspection and replacement of relays is recommended, especially in high‑traffic airfields.

Communication Failures

If the intensity control module communicates with the ALCMS via serial or Ethernet, a communication loss can prevent automatic control. Implement manual override and ensure redundant communication paths for critical systems.

Current Sensor Calibration

If the control module monitors actual current to verify the step, the current sensor may drift over time, causing false alarms or incorrect feedback. Periodic calibration against a reference ammeter is necessary.

LED PWM Interference

In LED systems using PWM dimming, the PWM frequency can interfere with other equipment or cause visible flicker if not set correctly. Ensure that the PWM frequency is above 200 Hz (preferably 1 kHz) to avoid flicker and comply with standards.

Power Supply Instability

Fluctuations in the AC supply voltage can affect the CCR output, especially in older thyristor‑based regulators. Use a stable mains supply or consider UPS protection for critical control electronics.

Likely Cause
Incorrect intensity step selected, manually or by a misconfigured ambient light sensor.
Diagnostic Steps
Check the currently selected step against the ambient light level and procedure, and verify the ambient light sensor's calibration if fitted.
Corrective Action
Correct the step selection, recalibrate or repair the ambient light sensor, and retrain staff on the step-selection procedure.

Likely Cause
Relay contact wear or welding in systems that switch CCR taps via relays.
Diagnostic Steps
Inspect relay contacts for wear, pitting, or welding, and verify the actual current against the selected step.
Corrective Action
Replace the worn or welded relay, and consider solid-state switching for high-traffic airfields.
Automatic Intensity Control Not Responding
Likely Cause
Communication loss between the intensity control module and the ALCMS.
Diagnostic Steps
Check the communication link status, test the serial/Ethernet connection, and verify the manual override function.
Corrective Action
Repair the communication link, use manual override until restored, and verify redundant paths are functioning.
False Fault Alarms on Current Feedback
Likely Cause
Current sensor calibration drift.
Diagnostic Steps
Compare monitored current against a reference ammeter at each step and review the calibration history.
Corrective Action
Recalibrate the current sensor against the reference ammeter, and replace it if out of tolerance.
Visible Flicker on LED PAPI Units
Likely Cause
LED PWM dimming frequency set too low, causing interference or visible flicker.
Diagnostic Steps
Measure the PWM frequency against the specification and check for correlation between flicker complaints and dimming level.
Corrective Action
Adjust the PWM frequency to above 200 Hz (preferably 1 kHz) per standard, and retest for flicker at all dimming steps.

Precautions

Safety & Operational Notes

Isolate Before Internal Work
Electrical Safety

De-energise and lock out the unit's incoming supply before opening the enclosure to access the step-selection contactors, control board, or sensor wiring, and verify zero energy before touching internal terminals.

Glide Path Safety Impact
Operational

The PAPI intensity setting directly affects a pilot's visual glide path indication on approach; any adjustment, calibration, or fault that could change intensity or step response requires airside coordination and, where the unit will be off-tolerance, a NOTAM.

Sensor Calibration Conditions
Verification

Verify the ambient light sensor reading against a calibrated reference meter under representative daylight/low-light conditions before accepting an automatic intensity control setting, since a miscalibrated sensor can leave the PAPI too bright or too dim without triggering a fault.

Contactor Arc Hazard
Electrical Safety

Step-selection contactors can arc on load; do not manually operate or inspect them while energised, and allow for a de-energised state before checking for contact wear or welding.

Command-to-Output Verification
Electrical Safety

After any control logic, configuration, or contactor work, verify commanded step against actual output across the full intensity range before returning the unit to automatic service, since a mismatch here directly changes what the pilot sees.

PPE & Grounding
Personnel Safety

Use insulated tools and appropriate PPE when working on live circuits or discharging capacitive components, and confirm the enclosure is bonded/grounded per the electrical design before closing it up.

FOD & Enclosure Integrity
Operational

Account for all tools and fasteners before closing the enclosure, and confirm the door/lid seal is properly reinstated to keep moisture and debris out of the control electronics.

Restore to Compliant State
Compliance

Do not leave the PAPI at an incorrect or unverified intensity step after maintenance; confirm command-to-output conformance and automatic control response before closing out the work and cancelling any associated NOTAM.

Field Insight

Engineering & Expert Notes

RS
By Rahul Sharma
Airfield Ground Lighting Specialist
Sensor Placement Bias Skews Every Step It Controls
Design

An ambient light sensor mounted where it sees partial shading from a nearby structure, or reflected glare off pavement, will bias every automatic intensity decision it makes, not just an occasional reading. Check the sensor's actual field of view against its surroundings, not only its calibration accuracy, when intensity complaints don't match expected daylight conditions.

Command-to-Output Mismatch Hides at the Boundary Steps
Troubleshooting

A contactor or driver stage that's starting to fail often still works correctly at the extreme steps (lowest and highest) while silently misbehaving at intermediate ones. Verify the full step range during commissioning and after any repair, not just the top and bottom steps that are easiest to check visually.

Flicker at One Step Points to That Step's Circuit, Not the Fixture
Diagnostics

When flicker is reported only at a particular intensity step, the fault is usually in that step's specific switching or driver stage rather than the LED module itself. Isolate testing to the reported step first before assuming the whole light unit needs replacement.

Contactor Wear Is Uneven Across Steps
Reliability

The step used most often under typical daylight conditions accumulates far more switching cycles than a rarely-used extreme step, so contactor wear across an array is rarely uniform. Track cycle counts per step where the control system supports it, rather than replacing contactors on a blanket time-based schedule.

Automatic Control Needs Testing Across Real Conditions, Not Just Bench Values
Verification

A sensor and control loop that responds correctly to a bench-simulated light level can still behave differently under actual dawn/dusk transitions, fog, or heavy rain, which change ambient light in ways a static test doesn't capture. Where possible, verify automatic response during a genuine low-visibility or transition period rather than relying solely on simulated calibration checks.

Manual Override Left Engaged Is an Easy Miss
Operational

A unit left in manual override after a maintenance visit or ATC-requested intensity change can sit at a fixed step for weeks without automatic response, unnoticed until conditions change enough that it becomes visibly wrong. Confirm the control mode is back to automatic as a standard close-out check, not only the intensity value itself.

Quick Answers

Frequently Asked Questions

Short answers about PAPI intensity control: brightness steps, CCR and LED control, signals, standards and maintenance.

Q1What is PAPI intensity control?

It is the component or subsystem that manages the brightness of PAPI light units. It receives commands from the tower, the ALCMS or a local manual panel and converts them into electrical signals for the lamps or LED modules, typically with 3 or 5 intensity steps.

Q2Why does PAPI need intensity control?

The red/white indication must stay readable across a huge range of ambient brightness. In full daylight a dim beam disappears against the sky, while at night high output would glare and make the red/white contrast harder to judge. The aim is legibility rather than brightness for its own sake.

Q3Where is PAPI intensity control implemented?

It can be integrated into the PAPI control unit as relay or solid-state outputs that switch the CCR's current taps, part of the CCR itself with the control unit sending a selection signal, or a standalone module with its own interface, often used in smaller or portable installations.

Q4What are the standard PAPI intensity steps?

A 5-step system uses 2.8 A, 3.4 A, 4.1 A, 5.2 A and 6.6 A, and a 3-step system uses 2.8 A, 4.1 A and 6.6 A. Step accuracy is typically ±2% of set current, and a step change takes under 1 second.

Q5How does intensity control work with a CCR?

The intensity module converts the command into relay contacts selecting a tap on the CCR's multi-tap transformer, or a digital signal such as Modbus. The CCR sets the output current, and every PAPI unit on the series circuit receives the same current, which determines its brightness.

Q6How is intensity controlled in LED PAPI systems?

The CCR may still supply a constant current such as 6.6 A while the LED drivers in each unit use PWM to set brightness. The intensity control module then sends a PWM or 0-10 V signal to the drivers independent of series current, and some systems embed the command in a two-wire power and data interface.

Q7What command sources and control signals are used?

Commands come from the ALCMS, a manual panel, an ambient light sensor or a tower switch. Control signals include dry relay contacts, 4-20 mA, 0-10 V, Modbus or proprietary interfaces, with galvanic isolation between control and power circuits.

Q8Which standards apply to PAPI intensity control?

The main references are ICAO Annex 14 (PAPI intensity requirements and step selection), FAA AC 150/5345-28, FAA AC 150/5345-56 (L-890 ALCMS) and IEC 61000-6-2 (EMC immunity). Always verify the current edition.

Q9How often should PAPI intensity control be checked?

Typical practice is an annual intensity step verification, relay contact inspection and current sensor calibration check, and a semi-annual communication link test. Your airport's approved maintenance programme takes precedence.

Q10What are the common PAPI intensity control problems?

Wrong manual step selection (too bright or too dim), relay contacts wearing or welding, communication failures that block automatic control (so keep manual override available), current sensor drift, LED PWM frequency set incorrectly causing flicker or interference, and unstable mains supply affecting CCR output.
