Taxiway Lighting Layout Generator

Describe the taxiway as straights and curves, pick ICAO or FAA, and get a plan-view layout of blue edge lights and green centreline lights, with fixture-by-fixture coordinates and a quantity schedule.

About this calculator

Every fixture is generated as an actual X,Y position and chainage, then drawn, counted and exported from that one list, so the drawing, the schedule and the CSV can never disagree. Curves are laid out on true offset arcs: the inner edge row is shorter than the outer row and is counted separately.

Methodology

How the Layout Is Built

The taxiway is walked segment by segment from the start point. Chainage c is distance along the centreline; lateral offset d is positive to the left of the direction of travel.

Straight segments

N = ⌈ L / S ⌉  →  Sactual = L / N

Edge rows sit at d = ±(W/2 + DE), the centreline at d = 0. All rows share the same stations, so edge lights stay opposite each other.

Curves

Rrow = RCL − d·(turn)  |  N = ⌈ Rrow·θ / Scurve ⌉

The inner edge row has a smaller radius and the outer row a larger one, so each row is spaced on its own arc length and the left and right quantities differ. If the inner row radius reaches zero, the tool flags it.

These are pre-filled, editable defaults. Closer spacing is common for low-visibility operation, and curve spacing depends on radius, so confirm every value against the standard and the approved project layout.

What this tool does not do

It does not draw stop bars, holding-position lights, lead-on/lead-off lights, runway-entry geometry or signs. An intersection segment only omits edge lights and keeps the centreline running; the real configuration there is project-specific.

FAQ

Taxiway Lighting Layout: Frequently Asked Questions

Quick answers on how the generator builds a taxiway lighting layout.

What does the Taxiway Lighting Layout Generator do?

You describe the taxiway as straights and curves, pick ICAO or FAA, and it produces a plan-view layout of blue edge lights and green centreline lights, with fixture-by-fixture coordinates, a quantity schedule and SVG, PNG and CSV exports. Every fixture is a real X,Y position and chainage, so the drawing, schedule and CSV always agree.

How do I describe the taxiway geometry?

Enter one segment per line in order of travel: a straight with its length, a curve with its centreline radius, angle and left or right direction, or an intersection with its length. The start point and heading are local project coordinates, with heading 0° along the +X axis and counter-clockwise positive.

How are straight sections spaced?

N = ⌈L ÷ S⌉ equal intervals, so S_actual = L ÷ N and the pitch never exceeds the design spacing. Edge rows sit at ±(W/2 + D_E) from the centreline, and all rows share the same stations so edge lights stay opposite each other.

How are curves counted?

The inner edge row has a smaller radius and the outer row a larger one, so each row is spaced on its own arc length and the left and right quantities differ. If a row radius reaches zero or goes negative, the tool flags it so you can increase the curve radius or reduce the width or offset.

Which spacing limits are pre-filled?

Edge lights: ICAO 60 m, FAA 200 ft on straights. Centreline: ICAO 30 m (15 m below 350 m RVR), FAA 100 ft (50 ft below 1,200 ft RVR). These are editable defaults. The centreline curve limit is taken automatically from each standard’s radius table (ICAO 7.5 m up to 400 m radius; FAA 25 ft under 400 ft radius, 12.5 ft below 1,200 ft RVR); edge-light curve limits are left for you to enter. An edge-light offset beyond 3 m (10 ft) from the pavement edge is flagged.

What happens at an intersection segment?

An intersection segment omits the edge lights and keeps the centreline running, and it is flagged for layout review because the real configuration there is project-specific. The tool does not draw stop bars, holding-position lights, lead-on and lead-off lights, runway-entry geometry or signs.

What can I export?

You can download the plan view as SVG or PNG, the full fixture schedule as CSV with ID, system, segment, chainage and X,Y in metres and feet, or print the layout. The plan has a whole-taxiway view and a zoomed detail window you can slide along the taxiway by chainage.

Is the result a final bill of quantities figure?

No. It is a calculated, nominal layout for design planning, with no serviceability allowance and no spares. A fixture at the joint between two segments is counted once. Verify the layout against the approved airport lighting layout and the governing standard.
