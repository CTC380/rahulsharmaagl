02 · Definition

What Is LED Airfield Lighting?

LED airfield lighting uses light-emitting diode technology in place of conventional lamp-based light sources. In an AGL installation, the LED fixture forms part of a larger electrical and control system, so it should be evaluated together with the complete AGL series-circuit infrastructure. An LED fixture that is suitable as a standalone product is not automatically suitable for every existing AGL circuit.

05 · Compatibility First

LED Retrofit Requires System Compatibility

These seven areas are specifically identified in the India AGL material as key considerations for LED retrofit projects.

01. CCR Compatibility

Output current, current steps, connected load, regulation and protection — LED load characteristics may differ from the existing lighting technology.

02. Series-Circuit Characteristics

Circuit length, current, cable characteristics, existing load and transformer configuration, evaluated as a complete electrical system rather than at fixture level.

03. Transformer Compatibility

Rating, primary current, secondary requirements, fixture load, insulation and existing condition — ignoring the transformer can cause compatibility problems.

04. Cable Condition

Insulation, continuity, existing joints, termination and physical damage — a new LED fixture cannot compensate for a deteriorated primary series circuit.

05. Connector Arrangement

Primary and secondary connector, cable size, connector type, electrical and mechanical compatibility, sealing condition.

06. Control & Monitoring Interface

Local/remote control, monitoring, fault indication, communication and ALCMS interface — the replacement fixture may need coordination with existing architecture.

07. Fixture Photometric Performance

Light intensity, beam distribution and alignment, colour/chromaticity and optical performance evaluated against applicable project requirements.

22 · LED AGL Applications in India

LED AGL Applications & Why Retrofit Needs Engineering Assessment

New airport projectsRunway rehabilitationTaxiway upgradesLED retrofitMaintenanceAirport modernisation

An airport AGL system can remain in service for many years, potentially containing older CCRs, series cables, transformers, connectors, control systems, mixed technologies and previous repairs.

The engineering question is not “Can this LED fixture be installed?” It is “Can this LED fixture operate correctly within this complete AGL system while meeting the applicable project requirements?” That distinction is central to successful retrofit planning.

FAQs

Frequently Asked Questions

Is LED technology relevant to Indian airport lighting projects?
Yes. LED technology is increasingly relevant to modern airport lighting projects, and AAI procurement documentation explicitly refers to both LED and non-LED airfield ground lights.
What should be checked before an LED retrofit?
CCR compatibility, series-circuit characteristics, transformer compatibility, cable condition, connector arrangement, control and monitoring interface, and fixture photometric performance.
Which applications can use LED AGL fixtures?
Runway edge, threshold, runway end, taxiway and centreline lights, approach lights, airfield signs and other compatible visual aids.
Is an LED fixture automatically suitable for an existing AGL circuit?
No. An LED fixture that is suitable as a standalone product is not automatically suitable for every existing AGL circuit. It should not be considered suitable for an existing system solely because it is advertised as an airport LED light or ICAO/FAA compliant; the complete system and applicable project requirements must be evaluated.
What is the difference between a new LED AGL installation and an LED retrofit?
A new installation designs the complete electrical system (CCR, transformer, cable, connectors, control) around the LED fixture from the start. A retrofit must instead check the existing CCR, series circuit, transformer, cable, connector and control system before deciding an LED fixture is suitable.
Does AAI procurement documentation cover LED airfield lighting?
Yes. AAI procurement documentation can explicitly refer to both LED and non-LED airfield ground lights, combining ICAO, FAA, DGCA-CAR and project-specific technical requirements.
