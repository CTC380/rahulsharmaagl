CCR & AGL Circuit Systems Comparison

MONITORING VS NON-MONITORING

A CCR Monitoring System supervises the CCR and/or lighting circuit and reports operating condition and faults. A Non-Monitoring System operates the lighting circuit without a dedicated function that provides continuous status or fault feedback. The distinction is about awareness, not about whether the lights work.

02 · CCR Monitoring System

Supervising the CCR and Lighting Circuit

A monitoring system supervises the condition of the CCR and/or its lighting circuit. Rather than only delivering current to the lights, it also feeds status and fault information back to the control system.

Monitoring architecture
              CCR
               │
       ┌───────┴────────┐
       │                │
       ↓                ↓
   LIGHTING          MONITORING
   CIRCUIT              │
       │                ↓
       💡          STATUS / FAULT
       │                │
       └────────────────┘
                        ↓
                 CONTROL SYSTEM

The monitoring information can be made available locally at the CCR, remotely at a control position, or both, depending on the installation.

03 · What Can Be Monitored?

Typical Monitored Parameters

The exact functions depend on the CCR and the monitoring architecture, but monitoring can include items such as:

  • CCR operating status
  • Output current
  • Circuit status
  • Fault conditions
  • Protection trips
  • Control/communication status
  • Alarm conditions

Governing principle: The system does more than simply supply current — it also provides information about system condition.

04 · Non-Monitoring System

Operating the Circuit Without Supervision

A basic non-monitoring arrangement focuses on operating the CCR and supplying the lighting circuit, without a dedicated continuous monitoring layer.

15 · Common Misconceptions

Myths vs Facts

Myth: A non-monitoring CCR is unsafe or non-compliant
Fact

A non-monitoring arrangement can still operate the lighting circuit correctly. The difference is in fault visibility and response time, not in whether the lights themselves function.

Myth: Monitoring makes the CCR itself more reliable
Fact

Monitoring does not change the reliability of the CCR hardware. It improves fault visibility, system awareness and response time.

Myth: Monitoring and remote control are the same function
Fact

They are related but different. Monitoring reports status to the operator; remote control lets the operator send commands to the CCR. A system can have either, both, or neither.

Myth: All monitoring systems report the same parameters
Fact

The exact functions monitored depend on the CCR and monitoring architecture provided — coverage can range from basic status to detailed current, protection and alarm reporting.

16 · Engineering Selection

Choosing Between Monitoring and Non-Monitoring

When selecting between a CCR monitoring system and a non-monitoring arrangement, consider:

  • Applicable ICAO/national requirements
  • Airport-specific specifications
  • Criticality of the runway/lighting system
  • Distance between CCR location and control position
  • Operational staffing and inspection regime
  • Required response time to faults
  • Budget and lifecycle cost
  • Integration with existing control systems
  • Maintenance resources available
  • Local versus remote monitoring needs
17 · Engineering Workflow

From Requirement to Commissioning

Determine operational requirement → identify applicable standard → decide monitoring requirement → select CCR and monitoring architecture → define monitored parameters → design local/remote status and alarm reporting → design lighting circuit → install and terminate → electrical testing → monitoring/alarm verification → commissioning.

18 · Engineering Verdict

Which System Applies Where?

Engineering Verdict

A CCR Monitoring System supervises the CCR and/or lighting circuit, providing status and/or fault information in addition to operating the lights. A Non-Monitoring System operates the lighting without a dedicated continuous monitoring function.

The final selection should always be based on the current applicable ICAO/national standard, operational criticality and approved airport design — not on a generic comparison alone.

MonitoringSupply + supervise, with status and fault information reaching the operator.

19 · FAQ

Frequently Asked Questions

Does monitoring make the lighting circuit itself work better?

No. Monitoring does not change how the lighting circuit operates — it adds visibility into the condition of the CCR and/or circuit and how quickly faults are known.

What is the biggest difference between the two systems?

A monitoring system supplies the lighting and supervises CCR/circuit condition, providing status and fault information. A non-monitoring system supplies the lighting without that dedicated continuous function.

Is monitoring the same as remote control?

No. Monitoring reports status from the CCR to the operator; remote control sends commands from the operator to the CCR. A system can be local or remote, and monitored or not, independently of each other.

Can monitoring information be shown both locally and remotely?

Yes. Local monitoring is typically displayed at the CCR itself, while remote monitoring transmits status and alarms to a central control system. Both can be provided in the same installation.

How does a fault get discovered without monitoring?

Without a dedicated monitoring function, a fault typically becomes apparent through operational observation, routine inspection or maintenance testing rather than an automatic alarm.

Is a non-monitoring system always the cheaper option?

Generally a non-monitoring system has lower equipment complexity and installation cost, but final selection must follow the applicable standard, operational criticality and approved airport design rather than cost alone.

20 · Standards & Reference Basis

Governing Documents

For an actual airport project, verify the current applicable editions of the relevant standards before using this comparison for project design.

FAA AC 150/5345-56 (ALCMS)

Specification for L-890 Airport Lighting Control and Monitoring System — the FAA equipment spec governing centralized monitoring, status and alarm reporting architecture.

IEC 61820-3-2 / FAA AC 150/5345-10

The underlying CCR specifications (constant current regulators, and regulator monitors under the L-828/L-829 distinction) that a monitoring architecture supervises. Note: IEC 61822:2009 was withdrawn in 2023 and superseded by IEC 61820-3-2:2023 — confirm the edition your project references.

ICAO Annex 14, Volume I

Aerodrome Design and Operations — CCR and lighting circuit requirements, including relevant monitoring and control provisions.

ICAO Aerodrome Design Manual

Applicable material covering CCR selection, circuit configuration and monitoring/control system guidance.

National CAA / DGCA / AAI Requirements

For Indian airport projects, also verify applicable DGCA requirements, AAI requirements, airport-specific technical specifications, project drawings and contract specifications.

Final Engineering Note

Monitoring architecture, monitored parameters and alarm reporting requirements can vary by CCR manufacturer and project specification. For final design, use the approved control-system and monitoring specifications rather than a generic comparison page.

CCR Monitoring and Non-Monitoring are complementary concepts describing how much operating and fault information reaches the operator, not whether the lighting circuit itself functions correctly.
