Installation Forms

The 25 forms that turn approved design and approved materials into a traceable field record — every installed cable, base can, fixture, transformer, connector, earth, sign, PAPI, approach light, CCR and ALCMS unit made physically identifiable, location-traceable, technically verifiable, and linked to its inspection and test records. Grouped into Installation Records and Installation Verification, this division is the field installation evidence layer that bridges Design/Procurement (Divisions 02–03) and Testing, Commissioning & Maintenance.

Where this fits — Division 02 designs the AGL system and Division 03 approves the materials for it; this division proves what actually went into the ground and how it was verified. INST-01 Installation Checklist Checklist
Purpose

The master checklist confirming that an AGL installation activity has been performed according to the approved design, drawings, specifications, and approved installation procedure.

Key Fields
  • Approved drawing available and latest revision verified
  • Approved material available and inspected
  • Method statement / risk assessment approved
  • Work permit and site access available
  • Tools, test equipment, and valid calibration in place
  • Correct location, orientation, elevation, and mounting
  • Cable connection, identification, and earthing completed
  • Visual inspection, snags, and corrective actions closed
Feeds every asset-specific installation record below.
INST-02 Site Installation Record Record
Purpose

A detailed record of installation activities carried out at a specific site or location, on a given date and shift.

Key Fields
  • Site Installation Record No.
  • Location / work area
  • Date, shift, weather
  • Contractor / supervisor / installation team
  • Activity performed, equipment installed, quantity
  • Tools and test equipment used
  • Inspection completed / installation accepted
  • Defects, snags, photographs, remarks
INST-03 Cable Laying Record Record
Purpose

Creates a traceable record of primary and other AGL cable installation, from drum to installed route.

Key Fields
  • Cable Record No. / Circuit ID / Cable ID
  • Cable type, manufacturer, size, voltage rating
  • Drum number, drum length, starting/end point, total installed length
  • Route, trench/duct, pulling method and tension
  • Bend, joint, and crossing locations
  • Correct cable, route, and identification verified
  • Continuity and insulation test completed
  • Traceability: drum → cable ID → circuit → route → location → test record
Feeds INST-04 Cable Route Record and INST-21 Cable Identification Record.
INST-04 Cable Route Record Record
Purpose

Documents the actual installed cable route and makes it traceable for future maintenance, against the designed route.

Key Fields
  • Cable ID / Circuit ID / Cable type
  • Start location / end location / route description
  • Drawing reference / trench or duct identification
  • Crossing, junction, and joint points
  • Coordinates / reference points / installed length
  • Designed route vs actual route
  • Deviation and reason for deviation / approval reference
  • As-built drawing / asset database reference
Feeds the as-built drawing and asset/cable database.

Frequently Asked Questions

Quick answers about the 25 Division 04 Installation forms, how they are grouped, and how they connect to the rest of the library.

Q1What is Division 04 — Installation Forms in the AGL Engineering Forms & Templates library?

Division 04 is a set of 25 installation forms (INST-01 to INST-25) in the AGL Engineering Forms & Templates library. It turns approved design and approved materials into a traceable field record, so that every installed cable, base can, fixture, transformer, connector, earth, sign, PAPI, approach light, CCR and ALCMS unit is identifiable, location-traceable and technically verifiable. The forms are grouped into 2 categories: Installation Records and Installation Verification.

Q2Which forms are included in Installation Records?

Installation Records (15 forms): INST-01 Installation Checklist, INST-02 Site Installation Record, INST-03 Cable Laying Record, INST-04 Cable Route Record, INST-05 Base Can Installation Record, INST-06 Fixture Installation Record, INST-07 Transformer Installation Record, INST-08 Connector Installation Record, INST-09 Earthing Installation Record, INST-10 Sign Installation Record, INST-11 PAPI Installation Record, INST-12 Approach Light Installation Record, INST-13 CCR Installation Record, INST-14 ALCMS Installation Record, INST-15 Cable Joint Record.

Q3Which forms are included in Installation Verification?

Installation Verification (10 forms): INST-16 Fixture Alignment Record, INST-17 Fixture Elevation Record, INST-18 Transformer Connection Record, INST-19 Connector Torque Record, INST-20 Earthing Connection Record, INST-21 Cable Identification Record, INST-22 Installation Quality Checklist, INST-23 Installation Snag List, INST-24 Installation Completion Certificate, INST-25 Installation Handover Record.

Q4What is the difference between the Installation Records and the Installation Verification forms?

The 15 Installation Records (INST-01 to INST-15) document what was installed and where, such as cable laying and route, base cans, fixtures, transformers, connectors, earthing, signs, PAPI, approach lights, CCRs, ALCMS equipment and cable joints. The 10 Installation Verification forms (INST-16 to INST-25) verify the work through alignment, elevation, connection, torque, earthing and cable identification records, then close it out through quality checking, snagging, completion certification and handover.

Q5What forms close out an AGL installation and hand it on?

The Installation Quality Checklist (INST-22) is the formal quality-control inspection of the completed installation. The Installation Snag List (INST-23) identifies, assigns and tracks deficiencies through to closure. The Installation Completion Certificate (INST-24) certifies that the defined scope is complete and ready for inspection and testing, and the Installation Handover Record (INST-25) transfers the completed package to testing and commissioning, operations or the next stage.

Q6Can the forms in Division 04 be downloaded and filled in?

Yes. Each form has a Download as Word button that produces an uncontrolled sample Word template with letterhead, a document-control block, ruled entry fields and a three-tier approval table, ready to print or fill on-screen. Checklist-format forms such as Installation Checklist (INST-01) download with a checkbox and a verified-by line for each item. The forms can also be searched by keyword or form ID.

Q7How does Division 04 connect to design, materials and testing?

Division 02 designs the AGL system and Division 03 approves the materials, while Division 04 proves what actually went into the ground and how it was verified. Every asset record here should trace back to an approved drawing and forward into the Installation Completion Certificate and Handover Record that release the work to testing and commissioning.
