INST-426 Incorrect Fixture Mounting

Symptom — A newly installed or recently serviced fixture is found mounted in a way that does not match the specified mounting method, frangibility requirement, or fixture orientation relative to its base, discovered during commissioning inspection or a subsequent flight check.

Equipment / System

In-pavement or elevated AGL fixture and its mounting interface to the base can, stake, or frangible coupling, as installed.

Possible Causes
HighFixture bolted directly to the base can without the specified frangible coupling or shear connection
HighWrong mounting bracket or adaptor used, not matched to the fixture/base can pair specified for that location
MedFixture mounted with packing/shims not called for in the installation drawing, altering its effective height or angle
MedElevated fixture mounted on a non-frangible or incorrectly rated stake in an area requiring frangibility
LowFixture mounting orientation reversed (e.g. lens-retaining ring installed backwards) without affecting light output enough to be caught visually
LowContractor substituted an available mounting kit from a different fixture family during installation
Required Tools
Installation drawing / mounting detail for the fixture typeTorque wrench matched to mounting hardwareFixture mounting gauge/template where specifiedFrangible coupling inspection kit
Safety Precautions
  • Coordinate airside access through ATC/apron control before approaching the fixture.
  • LOTO the circuit before disturbing the mounting or fixture.
Diagnostic Procedure
  1. ObservationCompare the as-installed mounting method against the installation drawing for that fixture type and location.
  2. MeasurementWith the circuit isolated, remove the fixture and inspect the mounting interface, coupling, and any packing/shims used.
  3. MeasurementConfirm the frangibility rating of the coupling or stake matches the specification for that area.
  4. DecisionMounting method matches the drawing after inspection → close out as correct. Mounting deviates from the drawing → correct to the specified method before commissioning proceeds.
  5. Fault LocationIsolate whether the deviation is at the fixture-to-coupling interface or the coupling-to-base-can interface.
  6. Root CauseConfirm the corrected mounting is stable, correctly torqued, and matches the drawing before final sign-off.
Test Points
Mounting method vs. installation drawing
Frangible coupling rating and condition
Fixture height and angle after correction
Torque on mounting hardware
Root Cause Verification

Re-inspect the corrected mounting, confirm fixture height/angle against the drawing, and verify frangible coupling function before final commissioning sign-off.

Corrective Action
  • Remove and remount the fixture using the correct coupling, bracket, or hardware specified in the installation drawing.
  • Replace any incorrectly rated frangible coupling or stake.
  • Remove unauthorised packing/shims and re-set to the specified height/angle.
Preventive Action
  • Verify mounting method against the installation drawing during the commissioning walk-down, not only at final flight check.
  • Provide contractors with fixture-specific mounting kits pre-matched to each location to prevent substitution.
  • Include a frangibility rating check in the commissioning checklist for all elevated fixtures.
Related References

Standards: FAA AC 150/5340-30, ICAO Annex 14 Vol I (frangibility requirements)

INST-427 Incorrect Fixture Height

Symptom — A fixture is measured during commissioning or a routine inspection to be higher or lower than the height specified in the design drawing, potentially affecting light distribution or frangibility/obstruction clearance.

Equipment / System

AGL fixture height as installed, measured from the surrounding pavement or ground reference to the top of the fixture lens or housing.

Possible Causes
HighBase can installed at the wrong elevation during civil works, before the fixture was ever placed on it
HighIncorrect number of shims/spacers used at the fixture-to-base-can interface
MedPavement overlay or resurfacing after original installation has changed the fixture's height relative to the new surface
MedWrong fixture model installed — same footprint but different overall height than specified
LowSettlement or frost heave of the base can since installation, gradually shifting height out of tolerance
LowMeasurement/verification step omitted during original commissioning
Required Tools
Height gauge / precision level matched to fixture typeInstallation drawing with specified height toleranceShim/spacer kit matched to fixture typeLaser level or surveying equipment for base-can elevation check
Safety Precautions
  • LOTO the circuit before adjusting fixture height.
  • Coordinate airside access through ATC/apron control before approaching the fixture.
Diagnostic Procedure
  1. ObservationMeasure the as-installed fixture height against the specified tolerance in the design drawing.
  2. MeasurementWith the circuit isolated, check the base-can elevation itself against the civil design, distinct from the fixture-to-base-can shimming.
  3. MeasurementIf pavement has been overlaid, confirm the current surface elevation used for the reference measurement.
  4. DecisionHeight deviation traced to shimming → adjust shims to bring the fixture within tolerance. Height deviation traced to base-can elevation or a pavement overlay → escalate to a civil/base-can correction rather than a fixture-level fix.
  5. Fault LocationConfirm whether the deviation is fixture-level (shimming) or base-can/pavement-level before deciding the scope of correction.
  6. Root CauseVerify the corrected height meets tolerance and remains stable under normal traffic loading.
Test Points
Fixture height vs. specified tolerance
Base-can elevation vs. civil design
Shim/spacer configuration
Height after correction, re-measured
Root Cause Verification

Re-measure fixture height after correction and confirm it is within the specified tolerance before commissioning sign-off.

Corrective Action
  • Adjust shims/spacers to bring the fixture to the specified height.
  • Escalate a base-can elevation error to civil works for correction.
  • Replace the fixture if the wrong model/height variant was installed.
Preventive Action
  • Include a height check with a calibrated gauge in the commissioning checklist for every fixture, not a sample.
  • Verify base-can elevation against civil design before fixture installation begins.
  • Re-verify fixture heights after any pavement overlay or resurfacing project.
Related References

SOP: SOP-INST-02 (Fixture Height Verification Procedure)

Standards: FAA AC 150/5340-30, ICAO Annex 14 Vol I

INST-428 Incorrect Fixture Orientation

Symptom — A fixture is found rotated out of its specified orientation — for example a unidirectional in-pavement light not facing the correct approach direction — discovered during a night flight check or photometric inspection.

Equipment / System

AGL fixture body and lens assembly as rotationally installed in its base can or mount, relative to the specified beam direction.

Possible Causes
HighFixture rotated during installation without reference to the orientation mark or beam-direction indicator on the housing
HighBase can itself installed rotated out of position during civil works, carrying the fixture's orientation error with it
MedFixture rotated during a maintenance visit (e.g. lens cleaning or bulb replacement) and not returned to the correct orientation
MedOrientation mark on the fixture worn, missing, or ambiguous, leading to an installation guess
LowFixture design symmetric enough that incorrect orientation was not obvious without a beam-direction check
LowAs-built orientation drawing inaccurate or not available to the installing crew
Required Tools
Compass or directional reference toolInstallation/orientation drawing for the fixture locationBeam-direction alignment fixture/jig where applicableNight flight-check coordination
Safety Precautions
  • LOTO the circuit before adjusting fixture orientation.
  • Coordinate airside access and any required runway/taxiway closure through ATC before working on an active surface.
Diagnostic Procedure
  1. ObservationConfirm the reported orientation issue via a night visual check or photometric reading from the specified viewing direction.
  2. MeasurementWith the circuit isolated, check the fixture's orientation mark against the specified beam direction on the drawing.
  3. MeasurementIf the base can itself appears rotated, verify its installed orientation against the civil/electrical design.
  4. DecisionOrientation error is at the fixture level → rotate and re-secure the fixture correctly within the base can. Orientation error is at the base-can level → escalate for base-can correction.
  5. Fault LocationIsolate whether the fixture, the base can, or both are misoriented.
  6. Root CauseConfirm the corrected orientation with a night visual or photometric check from the specified approach/viewing direction.
Test Points
Fixture orientation vs. specified beam direction
Base-can orientation vs. design
Night visual/photometric confirmation from the correct viewing angle
Orientation mark legibility
Root Cause Verification

Conduct a night visual check (or photometric measurement) from the specified direction after correction and confirm the beam is correctly oriented before sign-off.

Corrective Action
  • Rotate and re-secure the fixture to the correct orientation.
  • Escalate a misoriented base can for civil correction.
  • Re-mark or replace a fixture with an illegible orientation indicator.
Preventive Action
  • Verify fixture orientation against the drawing during the commissioning walk-down using a directional reference, not visual estimation alone.
  • Confirm base-can orientation before fixture installation begins.
  • Include an orientation check whenever a fixture is removed for maintenance and reinstalled.
Related References

SOP: SOP-INST-03 (Fixture Orientation Verification Procedure)

Standards: ICAO Annex 14 Vol I, FAA AC 150/5340-30

INST-429 Incorrect Fixture Alignment

Symptom — A fixture's vertical or horizontal aiming angle is found outside the specified tolerance during a photometric check, aiming survey, or pilot report of an inconsistent light pattern along a run.

Equipment / System

AGL fixture aiming mechanism (vertical elevation angle and/or horizontal azimuth) as set relative to the runway/taxiway centreline or approach path.

Possible Causes
HighAiming angle never set or verified against the design during original installation, left at a default or as-shipped position
HighAiming mechanism loosened by vibration or a maintenance visit and not re-verified afterward
MedAiming survey performed using an incorrect reference point or baseline
MedPavement settlement or resurfacing has changed the effective aiming angle relative to the new surface
LowAiming tool/jig used was not calibrated or was the wrong type for that fixture
LowA single fixture aimed correctly in isolation but inconsistent with the aiming pattern of the rest of the run
Required Tools
Fixture aiming tool/jig matched to fixture typeInclinometer / aiming angle gaugeAs-built aiming angle specification for the runPhotometric field measurement equipment where available
Safety Precautions
  • LOTO the circuit before adjusting fixture aiming.
  • Coordinate airside access through ATC/apron control before approaching the fixture.
Diagnostic Procedure
  1. ObservationIdentify whether the misalignment is a single fixture or a pattern across multiple fixtures on the same run.
  2. MeasurementWith the circuit isolated, measure the current vertical and horizontal aiming angle using a calibrated aiming tool.
  3. MeasurementCompare the measured angle against the specified aiming angle for that fixture's position on the run.
  4. DecisionSingle fixture out of tolerance → re-aim to specification. Pattern across multiple fixtures → investigate a systemic cause such as a reference-point or survey error.
  5. Fault LocationConfirm the specific angle (vertical, horizontal, or both) that is out of tolerance before adjusting.
  6. Root CauseRe-verify aiming with the calibrated tool after adjustment and, where practical, confirm with a photometric or visual check.
Test Points
Vertical aiming angle vs. specification
Horizontal aiming angle vs. specification
Consistency across the run
Photometric/visual confirmation after correction
Root Cause Verification

Re-measure the aiming angle with the calibrated tool after adjustment, and where practical confirm visually or photometrically before sign-off.

Corrective Action
  • Re-aim the fixture to the specified vertical and horizontal angle.
  • Re-survey and correct the reference baseline if a systemic pattern error is found.
  • Secure the aiming mechanism to prevent drift after adjustment.
Preventive Action
  • Include an aiming angle spot-check in the periodic PM cycle for fixtures on critical approach or centreline runs.
  • Verify aiming tool/jig calibration before each commissioning campaign.
  • Re-verify aiming after any pavement resurfacing or settlement event.
Related References

SOP: SOP-INST-04 (Fixture Aiming and Alignment Verification Procedure)

Standards: ICAO Annex 14 Vol I, FAA AC 150/5340-30

INST-430 Incorrect Torque

Symptom — Mounting hardware, connector fittings, or terminal lugs are found torqued outside the manufacturer's specified range during inspection — either over-tightened and showing signs of stress/cracking, or under-tightened and loose.

Equipment / System

Mounting bolts, connector gland fittings, and terminal lugs across fixtures, base cans, and transformer housings, assessed against manufacturer torque specifications.

Possible Causes
HighField crew used a fixed-setting or non-calibrated tool rather than a torque wrench set to the specified value
HighTorque specification not available to the installing crew, resulting in a best-guess tightening
MedTorque wrench used was out of calibration
MedOver-torquing performed deliberately in a mistaken belief that tighter is always more secure
LowCorrect torque applied initially but hardware has since loosened under vibration without re-torque
LowWrong hardware grade/material installed, giving an unpredictable relationship between applied torque and actual clamping force
Required Tools
Calibrated torque wrench matched to hardware size and rangeManufacturer torque specification tableThread/hardware inspection kitReplacement hardware matched to specification
Safety Precautions
  • LOTO the circuit before adjusting torque on any live-circuit component.
  • Inspect for cracking or thread damage before applying further torque to a component found over-tightened.
Diagnostic Procedure
  1. ObservationIdentify which hardware/fittings are suspected of incorrect torque and gather the manufacturer's specified torque value for each.
  2. MeasurementWith the circuit isolated, check current torque using a calibrated torque wrench without first loosening the fitting.
  3. MeasurementInspect over-torqued items for cracking, thread deformation, or crushed gaskets/seals before deciding whether they can simply be backed off to spec.
  4. DecisionUnder-torqued and hardware undamaged → re-torque to specification. Over-torqued with visible damage → replace the damaged component rather than merely adjusting torque.
  5. Fault LocationConfirm which specific fitting is out of tolerance rather than re-torquing every fastener in the area speculatively.
  6. Root CauseConfirm the tool used for correction is calibrated and set to the correct specification for that hardware.
Test Points
Measured torque vs. manufacturer specification
Hardware/thread/gasket condition
Torque wrench calibration status
Torque re-check after correction
Root Cause Verification

Re-check torque with a calibrated wrench after correction and inspect for any resulting damage before closing out.

Corrective Action
  • Re-torque under-tightened hardware to the specified value.
  • Replace hardware, gaskets, or fittings damaged by over-torquing.
  • Replace incorrect-grade hardware with the specified type.
Preventive Action
  • Issue torque specification tables alongside calibrated torque wrenches as standard field kit.
  • Verify torque wrench calibration on a defined schedule.
  • Include a spot-check torque verification in the commissioning checklist.
Related References

SOP: SOP-INST-05 (Torque Verification and Correction Procedure)

Standards: Manufacturer torque specification tables, FAA AC 150/5340-30

INST-431 Loose Mounting Hardware

Symptom — Fixture mounting bolts, base-can lid fasteners, or bracket hardware are found loose or missing during inspection, independent of a torque-value discrepancy, sometimes with the fixture itself visibly able to move.

Equipment / System

Fixture mounting bolts, base-can lid fasteners, and bracket hardware securing AGL components in place.

Possible Causes
HighVibration from continuous ground and aircraft traffic gradually working fasteners loose over time without a defined re-torque interval
HighFasteners not fitted with the specified lock washer, thread-locking compound, or self-locking nut where required
MedHardware never fully tightened during original installation
MedMissing fastener(s) not identified until a subsequent inspection
LowIncorrect hardware size/thread installed, unable to achieve a proper secure fit
LowCorrosion has caused a fastener to seize partially loose without being able to back all the way out
Required Tools
Torque wrench matched to hardware sizeReplacement fasteners matched to specification (including lock washers/thread-locker where specified)Visual inspection checklist for mounting hardware
Safety Precautions
  • LOTO the circuit before working on mounting hardware.
  • Coordinate airside access through ATC/apron control, and secure any loose hardware immediately as FOD risk on an active surface.
Diagnostic Procedure
  1. ObservationNote which specific fasteners are loose or missing and whether the fixture itself has visible play.
  2. MeasurementWith the circuit isolated, check remaining hardware for correct torque and confirm whether the specified lock washer or thread-locker is present.
  3. MeasurementInspect fastener condition for corrosion, thread damage, or wrong size/type.
  4. DecisionHardware intact but simply under-torqued or missing a locking feature → re-torque and add the specified locking feature. Hardware damaged, corroded, or wrong type → replace with correct specification.
  5. Fault LocationConfirm all fasteners at that mounting point are checked, not only the one initially reported loose.
  6. Root CauseDetermine whether the looseness is an isolated installation gap or a pattern across multiple locations pointing to a missing locking-feature specification in the original install.
Test Points
Torque on all fasteners at the mounting point
Presence and condition of lock washers/thread-locker
Fastener corrosion/thread condition
Play/movement in the fixture or lid after correction
Root Cause Verification

Re-check torque and confirm no play remains in the fixture or lid after correction, and re-inspect at the next scheduled PM cycle to confirm the fix has held.

Corrective Action
  • Re-torque loose hardware to specification.
  • Replace missing, damaged, or corroded fasteners with the correct type.
  • Add the specified lock washer or thread-locking compound where missing.
Preventive Action
  • Include a hardware torque and completeness check in the routine PM cycle for fixtures and base cans in high-traffic areas.
  • Specify and enforce use of locking hardware/thread-locker on all vibration-exposed mounting points.
  • Track fastener replacement history to identify locations with a recurring hardware-loosening pattern.
Related References

SOP: SOP-INST-05 (Torque Verification and Correction Procedure)

Standards: FAA AC 150/5340-30

INST-432 Incorrect Base Installation

Symptom — An in-pavement base can (L-867 or similar) is found installed in a manner that deviates from the design specification — wrong depth, wrong orientation, incorrect bedding, or wrong can size — discovered during commissioning or later maintenance access.

Equipment / System

L-867/base can assembly as installed in the pavement, including its depth, orientation, bedding material, and connection to conduit/duct.

Possible Causes
HighBase can set at the wrong depth relative to the finished pavement surface, affecting fixture height once mounted
HighBase can bedded directly in native soil rather than the specified bedding material, leading to instability or drainage issues
MedWrong size or model of base can installed for the fixture type specified at that location
MedBase can rotated out of the correct orientation for conduit entry or fixture alignment
LowBase can installed without the specified frost/heave protection in a cold-climate application
LowConduit stub-up not properly sealed or positioned relative to the base can's cable entry point
Required Tools
Installation/civil drawing for the base-can type and locationLaser level or surveying equipmentBase-can depth and bedding inspection kitReplacement base can matched to specification
Safety Precautions
  • LOTO the circuit and coordinate excavation/pavement work through the appropriate airside safety process.
  • Treat any excavation around an energised base can as a live-circuit hazard until isolation is confirmed.
Diagnostic Procedure
  1. ObservationCompare the as-installed base-can depth, orientation, and model against the civil/installation drawing.
  2. MeasurementWith the circuit isolated, excavate as needed to inspect bedding material, frost protection, and conduit connection.
  3. MeasurementConfirm the base-can model matches the fixture type specified for that location.
  4. DecisionDeviation is minor and correctable without full replacement (e.g. re-bedding, re-sealing conduit) → correct in place. Deviation is fundamental (wrong depth, wrong model) → replace/reset the base can.
  5. Fault LocationIsolate the specific aspect of the installation that deviates from the drawing before determining the scope of correction.
  6. Root CauseConfirm the corrected installation meets specification before backfilling and reinstating the pavement surface.
Test Points
Base-can depth vs. specification
Bedding material and drainage condition
Base-can model vs. fixture type specified
Conduit entry sealing and position
Root Cause Verification

After correction, confirm base-can depth, bedding, and conduit sealing meet specification before backfilling, and re-verify fixture height once the fixture is remounted.

Corrective Action
  • Reset the base can to the correct depth and orientation.
  • Replace inadequate bedding material with the specified type.
  • Replace the base can if the wrong model was installed.
  • Properly seal the conduit entry to the base can.
Preventive Action
  • Verify base-can depth and bedding against the civil drawing during installation inspection, before pavement is placed over it.
  • Confirm base-can model against the fixture schedule prior to installation.
  • Include frost/heave protection verification in cold-climate installation checklists.
Related References

SOP: SOP-INST-06 (Base Can Installation Verification Procedure)

Standards: FAA AC 150/5340-30, civil/electrical installation drawings

INST-433 Base Can Flooding

Symptom — A base can is found full or partially full of standing water during inspection or fault investigation, distinct from a connector-level water-ingress fault, indicating a drainage or sealing problem with the can itself.

Equipment / System

L-867/base can assembly, its drainage provisions, and lid seal, as installed at a specific pavement location.

Possible Causes
HighBase-can drainage weep hole or gravel sump blocked with silt, debris, or fines from surrounding bedding material
HighBase can installed below the local water table without the specified sump/drainage design for that condition
MedLid gasket failed or missing, allowing surface water to enter directly
MedSurrounding pavement grading directs surface runoff toward the base can rather than away from it
LowConduit connection not sealed, allowing water to enter via the duct run
LowA cracked base-can body allowing groundwater ingress
Required Tools
Wet/dry vacuum for pump-outMoisture detection meterBase-can lid gasket and drainage inspection kitLaser level for surrounding grade check
Safety Precautions
  • LOTO the circuit before pumping out or working in a flooded base can.
  • Treat a flooded base can as a serious shock hazard until the circuit is confirmed isolated and the connector/fixture wiring inspected.
Diagnostic Procedure
  1. ObservationNote the water level and whether it recurs after pump-out, indicating an active source versus a one-off event.
  2. MeasurementWith the circuit isolated, pump out the base can and inspect the drainage weep hole/sump, lid gasket, and conduit seal.
  3. MeasurementCheck the surrounding pavement grade and water table conditions for that location.
  4. DecisionDrainage/seal defect identified and correctable → clear or repair and monitor. Location is chronically below water table with inadequate sump design → escalate for a civil design correction.
  5. Fault LocationIdentify the specific entry/retention mechanism — blocked drainage, failed lid seal, or high water table — responsible for the flooding.
  6. Root CauseConfirm the base can drains properly after the next rainfall or irrigation cycle before considering the issue resolved.
Test Points
Water level in base can before and after pump-out
Drainage weep hole/sump condition
Lid gasket integrity
Insulation resistance of the fixture/transformer circuit after pump-out and drying
Root Cause Verification

Megger the affected circuit after pump-out and drying to confirm no lasting insulation damage, and re-inspect the base can after the next significant rainfall to confirm drainage is restored.

Corrective Action
  • Clear the drainage weep hole/sump of debris.
  • Replace a failed or missing lid gasket.
  • Reseal the conduit entry to the base can.
  • Escalate to civil works for a sump/drainage redesign where the water table is the underlying cause.
Preventive Action
  • Include base-can drainage condition in the routine PM checklist, particularly in low-lying or high-water-table areas.
  • Verify surrounding pavement grading directs surface water away from base cans.
  • Specify sump/drainage design appropriate to local water-table conditions during future installations.
Related References

SOP: SOP-CON-05 (Water Ingress Inspection and Remediation Procedure), SOP-INST-06 (Base Can Installation Verification Procedure)

Standards: FAA AC 150/5340-30

INST-434 Poor Drainage

Symptom — A broader pattern of standing water, saturated bedding, or repeated moisture-related faults is observed across a section of the field rather than at a single base can, pointing to a systemic drainage design or construction issue.

Equipment / System

Subsurface drainage system serving a section of the AGL installation — base-can sumps, drainage pipe/trench runs, and surrounding pavement grading, considered collectively rather than at a single location.

Possible Causes
HighDrainage trench or pipe run under-sized or blocked along its length, backing up water at multiple base cans
HighPavement grading in the area directs surface water toward the lighting corridor rather than away from it
MedDrainage system design did not account for actual local water-table or soil-permeability conditions
MedDrainage outfall point blocked or elevated, preventing the system from discharging effectively
LowSeasonal/weather extremes exceeding the design capacity of an otherwise adequate drainage system
LowSettlement of the drainage trench over time has created low spots that trap water rather than conveying it
Required Tools
Section-wide drainage/civil as-built drawingWater level/moisture survey across affected base cansDrain camera or rodding equipment for pipe run inspectionLaser level for grade survey across the section
Safety Precautions
  • LOTO all affected circuits before any base-can access during the survey.
  • Coordinate airside access and any required excavation through the appropriate safety process for that section.
Diagnostic Procedure
  1. ObservationMap which base cans in the section are affected and look for a pattern (e.g. all cans along one low-lying stretch).
  2. MeasurementWith circuits isolated, inspect the drainage trench/pipe run for blockage, undersizing, or damage along its length.
  3. MeasurementSurvey the surrounding pavement grade across the affected section to confirm whether it directs water toward or away from the lighting corridor.
  4. DecisionBlockage or damage found in the drainage run → clear/repair and re-monitor. Grading or design capacity is inadequate → escalate for a civil drainage redesign of the section.
  5. Fault LocationDetermine whether the issue is isolated to a single drainage run or reflects a section-wide grading/design problem.
  6. Root CauseConfirm the correction resolves the pattern across the whole affected section, not just the base can that first prompted investigation.
Test Points
Water/moisture pattern across affected base cans
Drainage pipe/trench condition along its run
Pavement grade survey results
Outfall condition and discharge capacity
Root Cause Verification

Re-survey the affected section after the next significant rainfall to confirm the drainage pattern has improved across all previously affected base cans.

Corrective Action
  • Clear or repair the blocked/damaged drainage run.
  • Correct pavement grading directing water toward the lighting corridor where practical.
  • Escalate to civil engineering for a drainage capacity/design review if the issue is systemic.
Preventive Action
  • Include a section-wide drainage walk-down after any significant rainfall event as part of storm-response PM.
  • Track base-can flooding incidents by location to detect emerging section-wide patterns early.
  • Review drainage design capacity against updated local rainfall/water-table data periodically.
Related References

Standards: FAA AC 150/5340-30, local civil drainage design standards

INST-435 Improper Cable Routing

Symptom — A cable is found routed in a manner that deviates from the design drawing — crossing an unintended path, sharing a duct with an incompatible circuit, or lacking the specified separation from other services — discovered during commissioning, fault-finding, or third-party excavation coordination.

Equipment / System

Primary or secondary cable routing between base cans, pull boxes, and the CCR/equipment vault, as installed relative to the design drawing.

Possible Causes
HighCable routed through the wrong duct/conduit, mixing circuits that were designed to be kept separate
HighMinimum separation from other utilities (fuel lines, communications, other electrical services) not maintained per specification
MedCable routed along a shorter but undocumented path during installation, leaving the as-built drawing inaccurate
MedCable crosses a pavement expansion joint without the specified protection or slack loop
LowCable routing technically functional but makes future fault location or maintenance access significantly harder than the designed route
LowMultiple circuits' cables bundled together without the specified separation, increasing induced-fault risk
Required Tools
As-built and design routing drawings for comparisonCable/duct tracerRoute verification survey equipmentDuct/conduit inspection camera where accessible
Safety Precautions
  • LOTO all affected circuits before excavation or duct access.
  • Coordinate with other utility owners before any excavation near cable routes to avoid third-party strikes.
Diagnostic Procedure
  1. ObservationCompare the as-built (or as-found) routing against the design drawing to identify the specific deviation.
  2. MeasurementWith circuits isolated, trace the actual cable route using a cable/duct tracer where the drawing and field condition disagree.
  3. MeasurementConfirm separation distances from other utilities and other lighting circuits at the points of concern.
  4. DecisionRouting deviates but meets separation and protection requirements → update the as-built drawing and close out. Routing violates separation, protection, or duct-sharing requirements → re-route or add protection to bring it into compliance.
  5. Fault LocationIdentify the specific segment where the deviation occurs rather than assuming the entire run is affected.
  6. Root CauseConfirm the corrected or documented routing is reflected accurately in the as-built record before closing out.
Test Points

INST-446 Wrong Component Installed

Symptom — A component installed at a given location is found, on inspection or after a related failure, to be a different part than the one specified for that location — broader than a specific wattage, connector, or fixture mismatch, covering any general component substitution.

Equipment / System

Any AGL system component (fixture, transformer, connector, control card, or ancillary part) as physically installed, compared against the specification for its installed location.

Possible Causes
HighA component substituted during an emergency repair from available stock without checking it against the location's specification
HighA design/specification change was made after the original component schedule was issued, and installation crews worked from the outdated schedule
MedTwo visually or functionally similar components confused during a bulk installation or delivery
MedA contractor substituted an equivalent-appearing component without formal approval or documentation
LowA component correctly specified but from an unapproved alternate supplier with different characteristics
LowOriginal specification documentation ambiguous or missing for that location, leading to an installer's best guess
Required Tools

Safety Precautions

  • Verify the replacement component's rating/specification before energising, to avoid introducing a new mismatch while correcting the old one.
Diagnostic Procedure
  1. ObservationIdentify the specific component and compare its nameplate/rating against the current component schedule for that location.

  • Investigate and correct related locations from the same batch if a pattern is found.
Preventive Action

INST-447 Wrong Wattage Transformer Installed

Symptom — An isolation transformer installed at a fixture is found to have a VA/wattage rating that does not match the specification for that fixture type, discovered during commissioning, a photometric check, or after a related overheating or dim-output fault.

Equipment / System

Isolation transformer VA/wattage rating as installed, compared against the rating specified for the fixture it feeds.

Possible Causes
HighA transformer from general stock substituted during installation or an emergency repair without confirming VA rating against the fixture
HighTwo similar-looking transformer models with different VA ratings confused during a bulk installation
MedA fixture upgrade (e.g. to a higher-output LED module) performed without a corresponding transformer rating review
MedTransformer rating correct at installation but a later fixture replacement changed the load without updating the transformer
LowLabelling on the transformer itself unclear or damaged, leading to a misidentification during installation
LowDesign schedule specified the wrong transformer rating for that fixture type from the outset
Required Tools
Fixture and transformer rating schedule for the siteTrue-RMS multimeter (CAT III) for current verificationNameplate verification on the installed transformerReplacement transformer matched to the correct VA rating
Safety Precautions
  • LOTO the circuit before replacing the transformer.
  • Treat an under-rated transformer under load as a potential overheating hazard and prioritise correction.
Diagnostic Procedure
  1. ObservationCompare the installed transformer's nameplate VA rating against the specification for that fixture type.
  2. MeasurementWith the circuit isolated, confirm the fixture's actual current/wattage draw and the transformer's rated capacity.
  3. MeasurementInspect the transformer for any signs of thermal stress consistent with sustained under-rating.
  4. DecisionTransformer rating is inadequate for the fixture load → replace with the correctly rated transformer. Transformer rating is adequate despite a labelling discrepancy → correct documentation only.
  5. Fault LocationConfirm the specific fixture/transformer pair affected before ordering replacement stock.
  6. Root CauseDetermine whether the mismatch originated at installation, a later fixture upgrade, or an original schedule error, to prevent recurrence.
Test Points
Transformer VA rating vs. fixture specification
Fixture actual current/wattage draw
Evidence of thermal stress on the transformer
Fixture output at all intensity steps after correction
Root Cause Verification

After replacing with the correctly rated transformer, verify fixture output at all intensity steps and confirm no thermal stress under normal load before closing out.

Corrective Action
  • Replace the transformer with the correctly rated unit for that fixture type.
  • Update the fixture/transformer schedule if a fixture upgrade was not previously reflected.
  • Correct the original design schedule if it specified the wrong rating from the outset.
Preventive Action
  • Review and update the transformer rating whenever a fixture is upgraded or replaced with a different load characteristic.
  • Maintain clear, legible nameplate ratings and verify them against the schedule before installation.
  • Include a transformer rating spot-check in the commissioning checklist.

INST-450 Commissioning Test Failure

Symptom — One or more required commissioning tests — insulation resistance, earth resistance, photometric, continuity, or functional intensity-step verification — returns a result outside the acceptable threshold during final acceptance testing of a new or modified installation.

Equipment / System

The full commissioning test suite for a new or modified AGL circuit or installation, covering electrical, mechanical, and photometric acceptance criteria.

Possible Causes
HighOne or more of the installation-level faults elsewhere in this division (mounting, height, earthing, connector, transformer, cable) is the underlying cause of the specific test failure
HighA component-level defect (fixture, transformer, connector) unrelated to installation practice but present from manufacture
MedTest performed with incorrect equipment, settings, or procedure, giving a false failure rather than a genuine defect
MedCircuit not fully settled after installation (e.g. cable insulation still curing, connections not yet seated under normal thermal cycling)
LowEnvironmental conditions at the time of test (temperature, humidity) affecting a marginal reading
LowTest acceptance threshold itself misapplied — using the wrong standard's limit for that specific test
Required Tools
Full commissioning test kit (megger, earth resistance tester, photometric equipment, multimeter)Commissioning test procedure and acceptance criteria for each test typeAs-built drawings and installation records for the affected circuitTest equipment calibration records
Safety Precautions
  • LOTO the circuit before conducting or repeating any commissioning test.
  • Coordinate airside access through ATC/apron control for any fieldwork required to investigate a failed test.
Diagnostic Procedure
  1. ObservationIdentify exactly which test(s) failed and by how much, distinguishing a marginal near-pass from a clear failure.
  2. MeasurementWith the circuit isolated, repeat the failed test using verified, calibrated equipment and the correct procedure to rule out a test-execution error.
  3. MeasurementIf the failure is confirmed, trace it to the specific installation or component fault using the relevant division of this troubleshooting atlas (e.g. earthing, connector, cable, transformer).
  4. DecisionRepeat test passes → original result was a test-execution error; log and close out. Repeat test confirms failure → investigate and correct the underlying installation or component fault before re-testing.
  5. Fault LocationIsolate the specific segment, component, or connection responsible for the failed reading.
  6. Root CauseConfirm the corrected installation passes the full commissioning test suite, not just the single test that originally failed, before final acceptance.
Test Points
Result of each failed test on repeat, with calibrated equipment
Underlying installation/component fault identified
Full commissioning test suite result after correction
Test equipment calibration status
Root Cause Verification

Repeat the full relevant commissioning test suite after correction and confirm all results meet acceptance criteria before issuing final commissioning sign-off.

Corrective Action
  • Correct the underlying installation or component fault identified as the cause of the test failure.
  • Repeat the test with verified, calibrated equipment if the original failure was a test-execution error.
  • Update commissioning records to reflect the corrected result and the root cause identified.
Preventive Action
  • Verify test equipment calibration before every commissioning campaign.
  • Build in a settling period where appropriate (e.g. for cable insulation) before final acceptance testing.
  • Cross-reference the correct acceptance threshold for each test against the applicable standard before testing begins.
